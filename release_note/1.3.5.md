# Release 1.3.5

## ハイライト
- **横断検索の拡張子フィルタ（`ext:` クエリ構文）** — `ext:pdf 見積` のようにクエリ先頭で対象ファイル種を絞り込み

## 詳細
### 新機能
- `ext:` クエリ構文（FR-SEF-01..04）: 先頭トークンのみ認識・カンマ区切り複数（`ext:pdf,docx`）・大文字小文字/先頭ドット/全角入力を正規化・先頭以外はリテラル検索語（逃げ道）
- 全 5 結果種に適用: アウトライン（`ext:out`）/ note md + アウトラインページ（`ext:md`）/ 添付の中身（実拡張子）/ 名前マッチ（絞り込み中はフォルダ名マッチ非表示）
- CLI（fractal-search）でも同一構文・`--scope` と AND（extension⇔CLI 一致契約 = ADRL-0059/0089）

### 改善
- 絞り込み対象外の添付は**抽出前にスキップ**（フィルタ付き検索の高速化・抽出キャッシュを汚さない）

### 互換性
- `ext:` を使わない検索は従来と完全同一（byte 不変）。旧バージョンの webview からのメッセージも安全に縮退
