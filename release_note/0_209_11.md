# Release 0.209.11

## ハイライト
- **Note タイトルが編集できるようになった**: Notes モードのファイルパネル見出し（従来「Outlines」固定）をクリックして note ごとの名前を付けられる。Activity Bar の FRACTAL NOTES ツリーにも反映される。
- **Reveal in Finder**: Outliner の file 添付 / md ページノードの実体を OS ファイラ（Finder 等）で表示。
- **Move Other Note**: ページ / 添付を別の Note へ移動（関連アセットを再帰的に複製、ID 衝突は上書き確認）。
- **Mindmap ノードの折り返しバグを解消**: 短文・アイコン付きノードが実機で必ず 1 文字折り返す問題を修正。
- 2 つの並行 sprint（note-title-finder-move / outliner-mindmap-mode iter30–32）を 1 ビルドに統合。breaking change なし（patch リリース）。

## 詳細な変更内容

### 新機能
- **Note タイトルの表示・編集（FR-NT-01/02/03）**: ファイルパネル見出しを編集可能にし、`outline.note` の root フィールド `noteTitle` に永続化する。未設定なら `path.basename(フォルダパス)` にフォールバック（後方互換）。空文字で確定するとクリアしてフォルダ名表示に戻る。変更は Activity Bar の FRACTAL NOTES ツリーに即反映される。
- **Reveal in Finder（FR-FR-01/02）**: Outliner の file 添付ノード・md ページノードの右クリックメニューに「Reveal in Finder」を追加。実体ファイルを OS ファイラで選択状態表示する。
- **Move Other Note（FR-MV-01/02）**: ページ / 添付を別の Note へ移動する。移動先へ関連アセット（画像・添付・同一 Note 内から参照される md）を再帰的に複製し、ID 衝突時は上書き確認する。移動元は登録から外し、物理実体は別途 cleanup で掃除する方針。

### 修正
- **Mindmap Mode のノード横幅（iteration 30–32、FR-021 の挙動修正・仕様変更なし）**: 短いテキスト（英数・ひらがな）やファイルアイコン付きノードが、実機（VS Code webview = Electron/Chromium）で必ず 1 文字分だけ折り返してしまう問題を修正。原因は `box-sizing:border-box` 下で幅算出のスラックが実質 1px しかなく、実機のフォント幅が headless 実測より数 px 広いため必ずはみ出していたこと。ノード幅の算出に border + 1 文字分の余裕（`BORDER_W=18`）を全ノード（アイコン有無問わず）へ加算し、編集中幅と確定後幅を一致させた。上限 280px クランプは維持（超過分のみクランプ）。

## 移行ガイド
- breaking change なし。`.out` / `outline.note` フォーマット・既存データはそのまま（`noteTitle` は optional で後方互換）。
