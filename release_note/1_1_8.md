# Release 1.1.8

## ハイライト
- Notes のタブ操作を一新: **cmd+w で閉じる / D&D 並べ替え / Close Other Tabs / Duplicate Tab**

## 詳細な変更内容

### 新機能
- **cmd+w（ctrl+w）**: アクティブタブを閉じる。閉じる前に自動保存（flush）されるのでデータは消えない。タブが 1 つだけのときはショートカットを奪わず、VS Code 自体のタブが閉じる
- **タブの D&D 並べ替え**: タブをドラッグすると挿入位置に縦線が出て、好きな並びに変更できる。並べ替えてもスクロール位置・サイドパネル状態はタブごとに維持
- **Close Other Tabs**: 右クリックしたタブだけ残して他を全部閉じる（内部的にも無駄なファイル再ロードなし）
- **Duplicate Tab**: 同じ md/outliner を新しいタブで開く。元のタブとは完全に独立（スクロール・サイドパネル非共有）
- 右クリックメニューは outliner タブでも表示（md タブは 3 項目・out タブは 2 項目）

### 変更
- タブ右クリックの「Open in VS Code Tab」を「Open in Standalone」にリネーム（動作は従来どおり standalone editor で開く）
