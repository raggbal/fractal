# Release v0.207.36 — Outliner お気に入り機能

## ハイライト

⭐ **Outliner お気に入り (Star) 機能** — Notes mode で頻繁に開く outliner を star 登録、別 view で flat list 表示

## 詳細

### 新機能

#### Notes 左 file panel の Star button
- 「新規フォルダ / 新規 outline」と同じ row に Star button (`#filePanelFavorites`) 追加
- click で view 切替: 通常 tree view ↔ お気に入り flat list view
- active 時は primary-strong (`#3994BC`) の teal で塗りつぶし

#### お気に入り flat list view
- お気に入り登録した outliner だけを **folder 階層なしの flat list** で表示
- 登録順 (先に star した順)
- 各 item は通常 tree view と同じ操作感 (click で開く、color 反映)

#### 右クリック context menu
- **通常 view**: 「★ Add to Favorites」 / 「★ Unfavorite」 toggle item を Rename の次に追加
- **Favorites view**: 「★ Unfavorite」のみのシンプル menu (簡潔操作)

#### Outliner editor header の ★ button (Notes mode のみ)
- view-toggle button の左に ★ button 追加
- 1 click で current outliner の favorite を toggle
- ON 時は primary-strong (`#3994BC`) で塗りつぶし、tooltip も「お気に入り解除」/「お気に入りに追加」で動的切替
- **Standalone outliner では表示されません**

#### 状態同期
- file panel 右クリック / header ★ button のどちらで toggle しても両方の UI が即時連動
- `outline.note` 更新 → `notesFileListChanged` broadcast → file panel 再描画 + outliner header ★ 状態更新

### 永続化

`outline.note` (NoteStructure JSON) に `favorites?: string[]` field を追加:

```jsonc
{
  "version": 1,
  "rootIds": [...],
  "items": {...},
  "favorites": ["abc-id", "xyz-id"]   // ← 新規 (お気に入り順)
}
```

S3 sync で folder ごと同期するため、お気に入り設定も他端末に引継ぎ。

### 互換性

- 旧 outline.note (favorites 無し) → `[]` 扱い、breaking change なし
- v0.207.36 で書いた outline.note を旧版 (v0.207.35 以前) で読んでも、`saveStructure` が全 field を JSON.stringify するため、**旧版で書き戻されても favorites field は破壊されない** (互換性維持)
