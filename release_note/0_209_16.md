# Release 0.209.16

## ハイライト
- **Notes の cmd+c / cmd+v ラウンドトリップで page md が作られないバグを修正**: Note A の node を B に貼り、B で複製した node を A に貼り戻すと、新しい pageId は振られるのに page md ファイルが作られず node から md が開けない問題を解消。

## 詳細な変更内容

### 修正
- **stale クリップボードによる誤 pageId 送出**: webview の内部クリップボードが貼り付け先パネルごとに保持され、コピーでクリアされず、テキスト一致だけで最優先されていた。ラウンドトリップの 2 回目に Note A の webview が cycle-1 の古いクリップボード（古い pageId）を保持して OS クリップボード（新 pageId）をシャドウし、存在しないコピー元 pageId を送っていた。
  - 修正: コピー操作ごとに一意 ID（copyId nonce）を内部クリップボードと OS クリップボードの両方に刻み、両者を照合。不一致なら OS クリップボード（＝最新のコピー元）を優先する純粋ヘルパを新設。
  - 防御: コピー元 md が存在しない場合に空ファイルを書かないバックストップを追加。
  - 外部アプリからのプレーンテキスト貼り付け（行分割）は従来どおり動作（回帰なし）。

## 移行ガイド
- breaking change なし。修正のみ。
