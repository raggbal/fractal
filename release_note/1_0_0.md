# Release 1.0.0

**最初のメジャーリリース 🎉**

Markdown・Outliner・Database・Mindmap を Notion のようにひとつの場所で管理する — Fractal のコアコンセプトが一通り揃いました。

## ハイライト

1. **Notion ライクな統合ワークスペース** — WYSIWYG Markdown、Dynalist ライクな Outliner（Database / Mindmap ビュー付き）、subpage 階層、note 単位の横断検索・タブ・Recent・Daily Notes
2. **AI ネイティブ** — 外部変更のリアルタイム反映（カーソル保持）に加え、AI エージェントが note を検索・読み書きできる **AI スキル 6 本**（structure / search / edit / doctor / summary / collect）
3. **Web クリッパー刷新** — 保存先プリセット + ★default で「開いて即クリップ」。Outliner だけでなく md への取込（subpage リンク追記）にも対応

## 変更点（0.212.0 以降）

### 新機能
- `fractal.showOpenInTextEditor` 設定（Open in Text Editor UI の表示切替）
- drawio の Open 2 ボタン化: **Open in VS Code**（hediet 拡張でタブ内編集）/ **Open in External**（draw.io Desktop 優先起動 → OS デフォルト fallback、3 OS 対応）
- Chrome 拡張 v0.3.0: フラットレイアウト・保存先プリセット・md 取込・Note 表示名
- AI スキル: ai_skills/ へリネーム + doctor / summary 新設 + edit の変更系（modify / --create-md / --target-md）+ search フィルタ（--tag / --checked / --note-name）

### バグ修正
- note のツリー先頭が md のとき空 outliner が表示される問題
- タブ閉じるボタンの位置（右端固定）
- Windows パス互換（ドロップ URI / 絶対パスリンク・画像解決。macOS 挙動不変）

## 対応 OS

- **macOS**: 動作確認済み
- **Windows / Linux**: 実装済み・未検証（[Issues](https://github.com/raggbal/fractal/issues) でのリクエスト歓迎 — 時間のあるときに対応します）
