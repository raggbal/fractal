# Release 1.2.0

## ハイライト
- **Daily Notes アーカイブが旧レイアウトを再生させるバグを修正** — タスクをアーカイブすると `<note>/dailynotes/` という旧構成フォルダが新規に作られ、次に note を開いたとき移行ゲートが再発していた
- **fractal:// page リンクの解決漏れ修正** — ヒント無し flat .out のページへのリンクが開けなかった
- README 大幅拡充（はじめかた・Export bundle・設定表）+ ショートカット HUD 更新

## 詳細な変更内容

### 修正
- `ensureDailyNotesFile` が dailynotes.out 新規作成時に flat ヒント（`pageDir: "."` /
  `imageDir: "./images"` / `fileDir: "./files"`）を書くようになった（従来はヒント無しで作られ、
  下流の書き込みが旧規約フォールバックに落ちていた）
- `notesArchiveTasks` のアーカイブ先解決を手書きフォールバック（`./dailynotes/`）から
  読み取り正典 `resolvePagesDir` / `resolveFilesDir` に置換。本体が読む場所に必ず書く
  （真の legacy note では legacy に、flat note では flat に — 読み書きが構造的に一致）
- `resolvePagePath`（fractal:// page リンク）も同型の取り残しを正典 `resolvePageFilePath` に置換

### 追加
- README: テーブル選択モードのショートカット表 / Export bundle 節 / AWS・PDF 設定表 /
  「はじめかた」の実手順化 / キービジュアルに Database・Mindmap ビュー言及
- cmd 長押しショートカット HUD: md エディタにテーブル選択モードのキー、Mindmap に
  cmd+C/X/V（子孫ごとコピー）と画像削除を追加
- Marketplace keywords を 12 → 28 に拡充（mindmap / pkm / second brain / notion 等）

## 影響を受けたユーザーへ
過去にアーカイブ機能で `<note>/dailynotes/` フォルダが出来てしまった note は、
起動時の移行ゲートで「移行する」を押せば flat 構成に統合されます（事前バックアップ付き）。
本バージョン以降はアーカイブしても旧フォルダは作られません。
