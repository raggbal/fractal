# Release 0.211.3

## ハイライト
- **インライン文字色**: markdown editor と outliner の node text で、選択したテキストに 20 色から文字色を付けられるようになりました。保存形式は `<span style="color:#hex">` なので、他の markdown エディタで開いても色が出ます（未対応のエディタでもテキストはそのまま読めます）。
- **inline 書式の「引きずり」を解消**: 太字・斜体・取消線・インラインコードを当てたテキストの直後に入力しても、前の書式を引きずらなくなりました。

## 詳細な変更内容

### 新機能
- **文字色（FR-IC）**
  - md editor: テキスト選択 → ツールバーの色ボタン、または cmd+/ の「Text Color」→ 20 色 swatch + None。
  - outliner: node text を選択（または node 全体）して右クリック → 「Text Color」。
  - 対象は header / 段落 / リスト / blockquote / node text。コードブロック・インラインコードは対象外。
  - 太字などと併用してもラウンドトリップで保たれます。
- **リストへの複数行ペースト（FR-PML）**: リスト項目に複数行テキストをペーストすると、各行が兄弟のリスト項目になります。

### 修正
- inline 要素（bold/italic/strike/code）直後の入力が書式を引きずる問題（作成直後・リロード後・全経路）。
- 色を付けた直後の入力が色を継続する問題。
- outliner の部分選択が node 全体に着色されてしまう問題。
- 複数行ペーストが 2 重に入る問題（Notes モード）。
- 翻訳ボタンが 2 つ並んで左が無反応だった問題。
- 日本語/中国語 IME 入力を壊さないよう、変換中の入力は横取りしません。
