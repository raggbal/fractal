# Release 1.3.6

## ハイライト

- **Office ファイルビューア** — 添付の `.docx` / `.xlsx` / `.pptx` を Fractal Note の中で開けるように（3 面すべて / **外部依存追加ゼロの自前実装**）
- **text / image ビューア** — .txt/.json/.js など 30+ のテキスト系と画像（SVG 含む）もアプリ内表示に
- **全ビューアで Cmd+F 検索 + 横断検索ヒットの位置着地** — Excel は該当シートのセル、PowerPoint は該当スライドへジャンプ
- **ファイル種別アイコン** — 📕 pdf / 📘 doc / 📗 xls / 📙 ppt / 🌐 html を全表示面に

## 詳細な変更内容

### 新機能

- **Word（.docx）ビューア**: 紙面幅カードレイアウト（pgSz/pgMar 幅一致・明示改ページで分割）。表（セル結合）・リスト番号（和文形式含む）・画像・ルビ・スタイル/テーマ継承（4 層解決）・ハイパーリンク・テキストボックス。数式や EMF 画像など未対応要素は明示プレースホルダに縮退。縦書き文書は警告バナー付き横書き表示
- **Excel（.xlsx）ビューア**: 行・列とも仮想化したスプレッドシートグリッド（10 万行 × 500 列でも滑らか）。数値書式（和暦・和文日付・1900 閏年バグ互換・date1904）・塗り/罫線/結合セル・シートタブ（非表示シートはグレー表示）・コメント・ハイパーリンク・オートフィルタマーカー。数式はキャッシュ値表示（式は tooltip・値なしは空欄）。罫線は Excel 同様に共有辺 1 本で描画
- **PowerPoint（.pptx）ビューア**: スライド一覧の縦スクロール表示（可視域のみ描画）。図形（プリセット/カスタムパス）・テーマ色・表・画像・グループ・縦書きテキスト・EA フォントスタック。パース層は MIT ライセンスの pptxtojson をファイル単位で移植（出典表記付き）し、レンダラは自前。チャート / SmartArt / アニメーションはプレースホルダ縮退
- **text ビューア**: 行番号付き読み取り専用表示・テーマ追従。大ファイルは chunk 描画（先頭即表示 + 逐次追記）で 10MB 級もフリーズなし。バイナリは明示メッセージ
- **image ビューア**: フィット初期表示・カーソル位置不動点のホイールズーム・パン・[フィット]/[等倍] ボタン・倍率表示・市松背景。SVG は `<img>` 限定の安全経路で表示解禁
- **ビューア内検索の全形式対応**: Cmd/Ctrl+F（または 🔍）でハイライト・件数・前/次・Esc 復帰。Excel は表示文字列（書式適用後）基準・現シート内検索
- **横断検索ヒットの位置着地**: 添付中身検索のヒットをクリックすると、Excel は `シート名!セル` の該当セルへ（シート切替 + 強調）、PowerPoint は該当スライドへ、text/Word は最初のマッチへ、検索語入りで着地
- **ファイル種別アイコン**: md リンク・outliner 添付・mindmap・ツリー・フォルダビューの全面で pdf=📕 / doc=📘 / xls=📗 / ppt=📙 / html=🌐（テキスト系・その他は従来の 📎。md の 📄 と紛れないための据え置き）。Notes ツリーのアウトライン（.out）は専用の「箇条書き入りドキュメント」アイコンに

### セキュリティ / 品質

- OOXML の zip 展開は三重ガード（宣言サイズ検証 + 単一エントリ 100MB + 累積 300MB）で zip bomb・壊れファイルに防御
- パスワード保護・サイズ超過ファイルは 3 形式とも明示のローカライズ済みメッセージに縮退
- 新規描画は innerHTML 不使用（XSS 経路ゼロ — grep 番人 TC 付き）・SVG は `<img>` 限定・依存追加ゼロ（npm diff 0 行）
- 検索側の抽出正典（doc-text-extract）と CLI ミラーは 1 バイトも変更なし（一致番人 TC）

### 変更

- md 本文の 📎 ビューア対象リンクは種別を問わずサイドパネルビューアで開くように（従来 pdf/html のみ → 全 kind へ汎化）
- `.svg` 添付が viewer 対象に（従来は常に外部起動）

## 移行ガイド

- breaking change なし。既存の pdf/html ビューア・外部起動の挙動は不変（対象外拡張子は従来どおり OS アプリ）
