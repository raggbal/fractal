# Release 0.209.2

## ハイライト
- **Mindmap Mode の実機フィードバック反映（iteration 22–23）**。v0.209.0 リリース後、実機での手動テストで見つかった 10 件の挙動バグ（toolbar/minimap 固定、開いた時の中心表示、複数選択、group 作成時の画面ずれ、type-to-edit、横幅追従、右空白）をすべて修正。
- すべて **既存 FR-021 の挙動修正**であり、仕様変更・新機能追加はなし（patch リリース）。

## 詳細な変更内容

### 修正（iteration 22）
- **#1 toolbar/minimap が消える/ずれる**: chrome overlay 化し、rerender・pan・スクロールをまたいで可視枠内に固定。
- **#4 minimap click**: クリック位置に対応するノードが画面中心付近へ来る（従来はどこをクリックしても左上へ飛んだ）。screen↔SVG 変換に viewBox origin 項（bounds.min − pad）を含めて是正。
- **#5 fit**: 全ノードが可視領域に収まる（左上に固まらない）。fit の座標変換を pad=120 込みで再実装。
- **group 作成**: 単一ノードの右クリック、および shift+click 複数選択からの右クリックで group を作成できる。

### 修正（iteration 23）
- **#2 開いた時に title が画面中心に来ない（巨大マップ）**: open-centering を縦のみ → **縦横とも** full center に変更。24 root / 293 node のような横に広いマップでも title 中心ノードが画面中心へ来る。
- **#3 shift+click が効かず単一しか選べない**: 素のクリックでアンカーノードを選択集合に含めるようにし、shift+click で選択が累積するよう修正。
- **#7 group を作ると画面がずれる**: グループ作成の rerender をまたいで viewport を凍結・復元し、画面を不動に保つ。
- **#8 確定ノードでいきなり文字を打てない**: 印字可能な1文字キーで編集モードに入り、そのまま入力できる（Space 不要）。非破壊（既存テキストを保持し末尾へ挿入）。
- **#9 英語だけ横幅が急拡大する**: 編集中の横幅測定を英語/日本語で対称にし、どちらも入力テキストの実幅に単調追従。上限 280px は維持。
- **#10 確定後に右側の空白が多い**: ノード幅の padding 想定（+24px）が実 CSS の水平 padding（20px）より過大だったのを是正し、右空白を削減。編集中の幅と確定後の幅を一致させた。
