# Release 1.3.19

## ハイライト

- **draw.io の図を file viewer で表示できるようになった** — `.drawio` / `.dio` / `.drawio.svg` / `.drawio.png` / `.dio.svg` / `.dio.png` を、sidepanel・ノート・standalone の 3 面で図として表示する。AWS アイコンなどの図形ライブラリも描画される
- **md 内の draw.io 画像に「Open in Viewer」** — ホバーボタンから viewer で図を開ける（md 内の表示そのものは変わらない）
- **sidepanel md のリンクから開いた viewer は md の上に重なる** — viewer を閉じると md がそのまま見える

## 詳細な変更内容

### 追加

**draw.io viewer**
- ツールバー: ページ選択（複数ページの図）・レイヤーの表示/非表示（ファイルは変更しない）・[−][+][⟲] ズーム・トラックパッドのピンチ・ドラッグでパン
- 描画中の外部通信は 0。図中の https 画像・Web フォントは空白になる（他の部分は表示される）。図中のリンクで画面遷移しない
- 描画ライブラリは draw.io v32.3.0（commit 96f8c7a）を同梱し、ビルド時に SHA-256 で照合する
- 図を含まない普通の svg / png（`.drawio.svg` 等の名前でも mxfile が無いもの）は画像として表示する。壊れた図は失敗表示になる
- VS Code の Explorer のダブルクリックは従来どおり既定のエディタ（hediet.vscode-drawio 等）で開く。fractal の viewer は「別のエディタで開く…」から選べる
- 新規作成（action panel）は従来どおり `.drawio.svg`

**md の Open in Viewer**
- md 内の draw.io 画像のホバーボタンに Open in Viewer を追加。Notes 内の md では viewer sidepanel、単体の md editor では viewer のタブで開く

### 変更

**viewer sidepanel と md sidepanel**
- sidepanel md の中のリンクから開いた viewer は md を閉じずに上に重なる（幅は md に合わせる）。閉じると md がスクロール位置もそのままで見える
- outliner の file node・ノートツリー・フォルダビュー等から開いたときは、従来どおり md を閉じて入れ替える。このとき outliner のカーソルは動かさない
- Esc は最前面の 1 枚だけを閉じる（viewer → md の順）。outliner にカーソルがあるときの Esc でも viewer を閉じる
- viewer を ✗ / Esc で閉じると、outliner のファイルノードから開いていればそのノードへカーソルが戻る。md や別ファイルを開いたことで viewer が閉じたときは戻さない
