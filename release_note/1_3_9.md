# Release 1.3.9

## ハイライト

- **PDF viewer の初期表示で横幅がはみ出ることがある問題を修正（幅追従の再フィット）**

## 詳細な変更内容

### 修正

**PDF が viewer ペインより大きく表示されることがある（間欠）**

- 症状: PDF を開いた直後、ペイン幅より PDF が大きく、右側が見切れる（毎回ではない）
- 根因: 横幅フィット（page-width）は「開いた瞬間のコンテナ幅」で一度だけ計算され、その後の幅変化（レイアウト確定の遅れ・ツリー開閉・sidepanel 幅復元・スクロールバー出現）に追従していなかった
- 修正: コンテナに ResizeObserver を張り、**手動ズームするまでは幅の変化に追従して自動で再フィット**（FR-FV-23 / ADRL-0099）。手動ズーム（[−][+]）後はズーム倍率を尊重して追従を停止。非表示中は再フィットせず、表示された時点の幅にフィット
- 併せて、viewer 破棄時に ResizeObserver が確実に解放されるよう cleanup 連鎖を修正（レビューで検出したリーク）
