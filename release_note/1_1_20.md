# Release 1.1.20

## ハイライト
- **リストの継続行（項目内改行）に対応** — Quip などから書き出した「リスト項目の下にインデントされた説明行」が崩れずに読み込めます
- **リスト内 Shift+Enter で項目内改行** — 新しい行頭記号を作らず、同じ項目の中で折り返せます

## 詳細な変更内容

### 新機能
- **CommonMark 継続行の読み込み**: リスト内で本文位置までインデントされた非リスト行を、直前の項目の「項目内改行」として取り込みます。従来はここでリストが分断され、後続のネストが崩れていました（Quip 貼り付けの主要な崩れ原因）
- **Shift+Enter = 項目内改行**: リスト内の Shift+Enter が継続行を作ります（Notion / Quip / Google Docs と同じ操作感）。文字の途中で押すと空白行を挟まずその場で折り返します。従来の「新しい項目を作る」は Enter と同じだったため置き換えました
- **書き出しも対称**: 継続行を持つリストを保存・コピーすると、マーカー幅でインデントされた継続行として markdown に出力されます（round-trip で崩れません）

### 修正
- 継続行を持つ項目をコピーすると改行が消えて連結される（bold を跨ぐ場合を含む）
- **複数行選択のコピーで、先頭行の選択範囲が中途半端だとリストとしてコピーされない** — 複数行選択なら先頭行の選択位置に関わらず必ずリスト markdown になります（単一行内の部分選択は従来どおりプレーンテキスト）

## 対象外（変更なし）
- アウトライナーの Shift+Enter（サブテキストを開く）は従来どおりです
- 継続行を使っていないリストの markdown 出力は 1 バイトも変わりません
