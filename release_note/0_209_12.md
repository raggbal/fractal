# Release 0.209.12

## ハイライト
- **Notes のオンディスク構成をフラット化**: Outliner ごとの `<outId>/` フォルダ隔離をやめ、Note フォルダ直下の md ＋ 共有 `images/`・`files/` に統合した。
- 既存レイアウトは後方互換で読め、手動マイグレーションコマンドで移行できる。breaking change なし（patch）。

## 詳細な変更内容

### 変更
- **共有フラットレイアウト**: page md は Note フォルダ直下（`<basedir>/<pageId>.md`）、画像 / 添付は共有 `<basedir>/images`・`<basedir>/files` に配置。`.out` の `pageDir="."` でフラットを表す。パス解決を `flat-layout` に一元化。
- **手動マイグレーション**: コマンドパレットの `Fractal: Migrate to Flat Layout` で既存 `<outId>/` ・ `_notes_md/` 構成をフラットへ移行。
- **S3 sync のキー構成**をフラットレイアウトに追従。

### 修正
- **共有アセットの誤削除防止**: 画像 / 添付を Note 内で共有するようになったため、item を別 Note へ移動する際に「他の生存 item がまだ参照しているアセットは削除しない」データロスガードを追加。削除は recoverable な API に寄せ、静的ゲート（即時 delete API の allowlist）を維持。

## 移行ガイド
- 既存データはそのまま読める（legacy `<outId>/` / `_notes_md/` を後方互換でフォールバック）。新規保存からフラットになる。まとめて移行したい場合は `Fractal: Migrate to Flat Layout` を実行。

## 検証
- flat-layout / migration / cleanup / S3-key 単体テスト green、`tsc --noEmit` exit 0、実機手動テスト（新規 Note 追加・既存 Note 非破壊）確認済み。
