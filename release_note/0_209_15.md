# Release 0.209.15

## ハイライト
- **md 移動 / 複製経路の md-to-md リンク扱いを統一**: 各経路でバラバラだった「md 内の別 md へのリンク」の扱いを、共通の再帰機構（closure 収集 + リンク URL 全体書き換え）に統一した。2 つの sprint 成果を 1 ビルドに統合。

## 詳細な変更内容

### 変更
- **Move Other Note（.out ページ）の再帰移動**: Notes の Outliner（`.out`）を別 Note へ移動したとき、各ページ md が参照する自 Note 内の md も再帰的に一緒に移動し、移動後もリンクが解決するようにした。残留参照がある md は移動せずコピー（元に残す）で data-loss を防ぎ、外部 Note リンクは相対書き換えで維持。循環検出あり。
- **Outliner → Outliner ノード貼り付けの完全再帰化**: 直接リンク先だけの 1 階層複製から、多段（A→B→C）を全複製してリンクを複製先に書き換える方式へ統一（md エディタへの貼り付けと同じ挙動）。

### 修正
- **貼り付け時のファイル名の部分文字列誤置換 / 同名衝突（HIGH）**: `handlePageAssets` の画像・ファイル・md リンク書き換えを、リンク URL 全体を単位にする方式へ是正。`a.png` の改名が `banana.png` を壊す不具合、同名（別フォルダ）画像が衝突して片方失われる不具合を解消。

## 移行ガイド
- breaking change なし。挙動の統一と修正のみ。既存の絶対パス禁止・data-loss ガードは維持。
- D&D インポート（Finder / Explorer から md をドロップ）の md リンク再帰は本リリースのスコープ外（既知の残課題）。

## 検証
- .out 再帰移動（TC-OUT-01〜40 + multi-root dedup）/ handlePageAssets 再帰（TC-HPA-01〜31）単体テスト green。full unit green、`tsc --noEmit` exit 0。load-bearing TC は counterfactual 検証済み。
