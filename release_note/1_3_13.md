# Release 1.3.13

## ハイライト

- **複数選択に対応**（note ファイルツリー / linkedfd / outliner / mindmap）— shift+click で範囲、cmd/ctrl+click で単品トグル。選択したまま D&D すると全件まとめて処理される
- **linkedfd ⇄ note ツリーの D&D が「複製」になった** — 元は 1 バイトも変わらない（sidepanel md との 2 方向は従来どおり「移動」）
- **node のバレットを掴むと、その node の添付（md ページ / 📎）も一緒に運ぶ** — 小さいアイコンを狙わなくてよい
- **「Outliner に送る」/「linkedfd に送る」** — 右クリックから面をまたいで送れる
- **右クリックメニューが画面外に見切れなくなった**（7 面すべて）

## 詳細な変更内容

### 新機能

**複数選択（note ファイルツリー / linkedfd / outliner / mindmap）**

- **shift+click / shift+↑↓** = 連続範囲（伸長も収縮も）。**cmd/ctrl+click** = 単品トグル（不連続選択）。Esc で解除
- 選択したまま D&D すると全件が処理される。宛先は **linkedfd / outliner / md エディタ**、そして**ツリー内の移動**（フォルダに入れる・並び替え・`.out` や md item の中へ）
- 種別が混ざっていても **1 バッチ**でまとまって動く（1 件ずつ N 回の処理にはならない）
- 失敗はアイテム毎に独立（1 件失敗しても他は成立）。結果は**通知 1 回**にまとめて出る。件数が多いときは 200 件超で確認ダイアログ、2,000 件超は中断（0 件処理）
- フォルダ行は選択対象に入らない。`.out` は外部の面（linkedfd / outliner / md）への転送対象外で、除外した件数は通知に出る
- **Outliner の Cmd+A で全 node 選択**（ショートカット HUD に載っていたのに未実装だった）。選択のハイライトはフォーカスが動いても消えず、色は全ビューで共通の water-blue

**node 添付の一括転送（バレット D&D）**

- outliner の **node バレット**を note ファイルツリーへ drag すると、その node が持つ **md ページ / 📎 file 添付**が一緒に運ばれる
- **子孫 node の添付は含まない**（自分自身の添付だけ）
- 既存の 📎 / 📄 アイコンからの D&D は**そのまま併存**（バレット経路は「小さいアイコンを狙わずに済む」代替）
- mindmap の node でも同じように効く。**複数選択した node**の添付も一括で送れる
- node に直付けした画像は転送**しない**（note 内の移動で唯一「複製」になってしまう非対称を避けるため。rc 途中で入れて撤回した）

**「Outliner に送る」（linkedfd → outliner）**

- linkedfd の右クリックから、選択したファイル群やフォルダを **outliner の root 先頭**へ取り込む（実体は note へコピー、フォルダは構造を node で再現）
- Import folder と同じ engine で、違いは起点と挿入位置だけ。送り先の `.out` はサブメニューで選ぶ

**「linkedfd に送る」（outliner → linkedfd）**

- outliner の node 右クリックから、選択した node 群を**登録済みの folder link** へフォルダ木として書き出す
- 送り先は**サブメニューで folder link を選ぶ**（任意フォルダのダイアログではない）。リンク切れは選べず、0 件なら理由付きで無効表示
- 選択に親子が混ざっていても**最上位だけ**が root になる（二重出力にならない）

**フォルダを outliner エディタに D&D で Import folder**

- VS Code の Explorer からも Finder からも可。件数上限・確認ダイアログ・資産の随伴は Import folder と同じ

### 改善

**linkedfd ⇄ note ツリーの D&D が「複製」になった**

- **元は一切変わらない** — 実体もツリー台帳のエントリも残る。md の場合、本文が参照する画像・📎・subpage md も**元側に全部残る**（コピーされるだけ）
- ドラッグ中のカーソルがコピーの見た目になる
- **「移動」のまま変わらない経路**: linkedfd ⇄ sidepanel md（複製成功 → 元を trash）と、linkedfd 内のフォルダ間移動

**Import folder の二重取り込みを解消**

- 取り込む `.md` が参照している画像・📎・subpage md は、**その md が連れて行く**だけになり、別 node としても現れる二重化が止まった
- 取り込んだ実体へのプレーンリンクは、取り込み後の位置に張り替わる
- 中身が全部 md 側に吸われたフォルダは、空 node を作らない

### 修正

- **右クリックメニューが画面外に見切れなくなった** — 7 面すべて（outliner node / outliner 列ヘッダ / note ツリー / md エディタ / mindmap / linkedfd / タブ）で、端では反転し、はみ出す分は画面内へ寄せ、ウィンドウより長いメニューはスクロールする
- **Redo（`Ctrl+Shift+Z` / `Ctrl+Y`）が Fractal 以外の場所でも発火していた** — 他の 7 個のショートカットと同じスコープに絞った（GitHub issue #2）
- ツリーの item と item の**谷間に落とすと、その間に入る**ようになった。ツリーの `.out` / md item は中央の帯で drop を受ける
- リスト項目の中で 1 行だけ貼り付けたときに普通のテキストになる / リスト行頭のアイコン付きリンクで Enter を押してもアイコンが消えない / md エディタへの複数ファイル同時 D&D で全部添付される
- mindmap: root ノードの縦積みが**実測の高さ**で行われる（重なりが出ない）。`.out` のタイトルが空でも title 中心ノードから放射する
- 壊れた `.out` を開いたときに「空の outliner」として黙って開かず、失敗を通知する
- ショートカット HUD のトリガー・選択色・移動系の取り残し経路など、実機テストで見つかった細部を多数修正
