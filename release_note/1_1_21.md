# Release 1.1.21

## ハイライト
- **note の markdown エディタで Cmd+F 検索が効かないバグを修正**

## 詳細な変更内容

### 修正
- **Notes 内 md エディタ（メインペイン）で Cmd+F / Cmd+H が動かない**: outliner のグローバル検索ショートカットが md ペインにフォーカスがあるときもキーを先取りし、不可視の outliner 検索を開いていました。md ペインフォーカス時は md エディタ自身の文書内検索（検索 / 置換）が開くようになります。standalone md・sidepanel md は従来から正常で、変更ありません。outliner タブでの Cmd+F（テキスト検索）も従来どおりです
