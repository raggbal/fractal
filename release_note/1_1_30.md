# Release 1.1.30

## ハイライト

- **table の Excel 化**: セルの select/edit 2 モード・矩形範囲選択・範囲 copy/cut/paste(Excel と相互運用)・**セル結合**・**行フィルタ**を一括導入

## 詳細な変更内容

### 新機能

- **select/edit モード(FR-TSL)**: click = セル選択(枠表示・キャレットなし)/ 矢印移動 / Shift+矢印・ドラッグ・Shift+click で範囲選択 / タイプ = 置換・Enter/F2/ダブルクリック = 編集 / edit 中は Enter = 確定(同セル)・Tab = 確定+右・Esc = 破棄・矢印はセル内に閉じ込め / 最終セル Tab = 行追加
- **範囲クリップボード(FR-TSL-03)**: TSV + HTML で Excel と双方向。paste は左上起点・行は自動追加・**列も必要数追加して全部貼る**・結合構造も再現。undo 1 回
- **セル結合(FR-TMG / ADRL-0054)**: toolbar の ⊞/⊟。md は `<!-- fractal-merged-table -->` マーカー + `<`/`^` トークン(マーカー gate = 既存データの `<`/`^` は不変)。行/列の挿入・削除は Excel 準拠で結合が伸縮。Excel の結合表を貼ると結合ごと再現。列リサイズも結合対応(grid 座標)
- **行フィルタ(FR-TFL)**: toolbar の検索欄で行絞り込み(表示のみ・md 不変・PDF は全行)。構造操作・貼り付けで自動解除、フィルタ中の結合/解除は不可

### 補足

- 「Enter で行追加」は「最終セルで Tab」に移動しました(Enter は編集の確定/開始に使用)
- 外部エディタでは結合 md は `<`/`^` が文字として見えます(graceful degradation)
