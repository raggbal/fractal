# Release 1.1.17

## ハイライト
- **tag サジェストをキーボードで選択** — Search box から手を離さずに ↓←→Enter でタグ検索
- **タスクモードの適用範囲を選択可能に** — 「トップレベルのみ / 全てのノード」を ON 時に選択・.out に記録
- **未編集ノードの #tag がサジェストに出ないバグを修正**

## 詳細な変更内容

### 新機能: tag サジェストのキーボード選択（全 3 view）
1. Search box にフォーカス → タグのサジェストバーが出る（既存）
2. **↓** でサジェストに入る（1 個目がハイライト）
3. **← →** で選択移動（端で停止）
4. **Enter** で Search box に反映（既存値に空白区切りで追記）+ 検索実行
5. **↑ / Esc** で選択を抜ける（値は不変）
- フォーカスは Search box に残るので、選択をやめてそのまま入力を続けられる。マウス操作は従来どおり

### 新機能: タスクモードの適用範囲（taskScope）
- ON でポップアップ「**トップレベルのみ / 全てのノード**」を表示（両方 primary ボタン・前回選択がデフォルトフォーカス・Enter 一発確定・Esc キャンセル = ON しない）
- 選択は `.out` の `taskScope` に記録。**OFF 時はその範囲だけ解除** — トップのみなら手動で子に付けたチェックボックス（Cmd+Shift+X）は残る。「全て」なら全解除
- **ON 中に追加した新規ノード**にも範囲に従ってチェックボックスが自動付与
- 後方互換: taskScope の無い既存 .out は「トップレベルのみ」扱い = 従来と同一動作。「トップのみ」選択時はファイルに何も書かないため旧ファイルは byte 単位で不変

### 修正: タグの収集漏れ
- タグはノード編集時にしか本文から抽出されず、**一度も編集していないノード・外部ツール由来・外部編集されたノードの #tag がサジェストにも #tag 検索にも出なかった**
- ファイルを開くたびに全ノードのタグを本文から再計算するように変更（本文が単一の真実。古い保存値も開いた瞬間に自己修復）
