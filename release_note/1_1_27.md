# Release 1.1.27

## ハイライト

1. **サイドパネル md への D&D 全面開通** — outliner の 📎/page node、md の 📎/subpage リンクを、メイン md にもサイドパネル md にも drop できるようになりました（従来はツリー項目しか受けられず無反応）。
2. **note を跨ぐ D&D は cmd+x と同じ意味論に統一** — dest note へ実体コピー + 元の台帳除去 + **元実体は温存**（orphan 化 → 元 note の Clean Notes で回収）。リンク切れ・データ損失経路を封鎖。
3. **md リンク → outliner の drop も新設** — D&D マトリクスの残セルを裁定し、対象セルを完備。

## 詳細な変更内容

### 新機能

- **FR-TF-19: md editor（main / sidepanel 対称）の drop 受け 4 種**
  - outliner 📎 file node → 📎 リンク添付（元 node は子なしなら削除・子ありは添付だけ外れる）
  - outliner page node → subpage リンク挿入（元 node は page 属性だけクリア・子は温存）
  - md 📎 リンク / subpage リンク → リンクの移動（元 md から消える）。自分自身への drop は何も起きません
- **FR-TF-20: outliner の drop 受け 2 種** — md 📎 リンク（file 添付 node 化）/ subpage リンク（page node 取込）。補助線どおりの位置に入ります

### 変更

- **FR-TF-18: cross-note D&D = source orphan 契約（ADRL-0051）**
  - 別 note の md/outliner へ drop すると: dest note の `files/`（md は note 直下）へ実体コピー → dest 内相対リンクを書く → 元の台帳（tree item / node / リンク）を除去 → **元の実体はディスクに残す**（トラブル時に復旧可能。元 note の Clean Notes がレポートし、承認で回収）
  - 既存の「tree md → 別 note の sidepanel」は従来元 tree item を残していましたが、この契約に統一（除去）
  - note を跨ぐ `../` リンクは書きません（Clean Notes が保護できず、実体が誤回収されるとリンク切れになるため）

### 修正

- **tree file → サイドパネル md の drop が無反応**: bridge の片ブロックにのみメソッドが定義されていた配線欠落を修正。両ブロックの対称性はブロック単位の wiring guard（TC-RG-02）で恒久保証
- **`# C#` のような末尾記号タイトルの切り捨て**: 新設経路の H1 抽出を CommonMark 準拠の正典関数へ置換（失敗 DB 3 回目の再発 — 番人 TC 追加）
