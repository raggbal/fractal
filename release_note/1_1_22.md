# Release 1.1.22

## ハイライト
- **アウトライナーの node 内で Shift+Enter 改行ができるようになりました**（mindmap と同じ操作感に統一）
- **subtext の開閉は Shift+Cmd+Enter に変更**（トグル化）

## 詳細な変更内容

### 新機能
- **node text 内改行**: outliner / table view の outline 列で Shift+Enter がその場での折り返しになります。mindmap では以前から改行できており、view 間の不一致が解消されました。改行は `.out` にそのまま保存され、再読込でも残ります
- 改行は**表示・編集専用**です: node を md としてコピー / llms.txt / 外部エディタへの plain text 貼り付けでは空白 1 個に潰され、1 node = 1 行が保たれます（外部貼り付けで node が分裂しません）。outliner 内の copy/paste は改行を保持します

### 変更
- **subtext（ノート）の開閉が Shift+Cmd+Enter に**（従来 Shift+Enter）。開くも閉じるも同じキーのトグルです。subtext の中では Shift+Enter は普通の改行になりました
- **page node のタイトル同期は先頭行のみ**: 2 行目以降を足しても md の H1 は 1 行目のまま。md 側で H1 を変えると node の 1 行目だけ変わり、続きの行は保持されます。mindmap で改行を入れた page node が H1 を壊しうる潜在バグも同時に修正

### 変わらないもの
- Enter（兄弟ノード追加）/ Option+Enter（子ノード追加）/ Cmd+Enter（ページを開く）
- mindmap の改行挙動
