# Release 0.209.0 — Mindmap Mode

## ハイライト

- **Outliner に Mindmap Mode を追加**（3rd view mode）。同じ `.out` をマインドマップとして描画・編集でき、Outliner View / Table View と相互に切り替え可能。キーボードだけで作成・編集・移動が完結し、ノード/線の自由スタイル・グループ・関連線・添付・エクスポートまで一通り揃う。

## 詳細な変更内容

### 新機能: Mindmap Mode (FR-021)

- **表示切替**: View Toggle で Outliner View → Table View → Mindmap Mode を循環。`viewMode` を `.out` に保存（旧 `.out` は Outliner View 既定で後方互換）。
- **レイアウト**: radial（中心から左右両側へ横展開）/ right / left / balanced。title を中心ノードにして root 群を左右に振り分け。d3-hierarchy + d3-flextree による可変ノードサイズで重なりを回避。
- **キーボード操作**（マウス不要）: Enter=弟追加、Shift+Enter=兄追加、Tab=子追加（いずれも追加後は非編集）、Space=編集開始、矢印=空間フォーカス移動、Delete=削除、undo/redo/copy 等。
- **編集の質**: リッチノード（📄/📎 アイコン・画像サムネ・タグ・チェックボックス）。改行なしの長文は編集中に横幅がリアルタイムで広がる（上限 280px、最長行にフィット）。編集中はノード DOM を作り直さず caret/IME を保護、フォーカスを外すと自動保存（未確定テキストの消失を防止）。
- **配置**: 内側エッジ合わせ（right 側=左端揃え、left 側=右端揃え）。接続線はノードのエッジに正しく接続。
- **スタイル・構造**: ノードの塗り/枠線/形状、線の種類/色/太さを自由設定（サブツリー継承 + 個別上書き）。複数ノードのグループ化（Boundary）、ノード間の関連線（Relationship）、親を持たない Floating Topic の自由配置。
- **添付**: file / image / markdown を Outliner と同様に添付（markdown は side panel で開く）。
- **エクスポート**: PNG / SVG / OPML / Markdown。
- **ビューポート**: pan / zoom / fit / minimap。編集を確定しても画面がずれない（レイアウトの bounds シフトを viewport で補償）。ノード移動・追加時は、対象が画面外のときだけ 1 ノード分だけ最小パンし、実ウィンドウ端から余白を確保する（中央には飛ばさない）。
- Single mode / Note mode の両 provider で動作。

## 移行ガイド

- breaking change なし。既存の `.out` はそのまま Outliner View で開き、View Toggle から Mindmap Mode に入れる。Mindmap で編集した内容（レイアウト種別・ノードスタイル・グループ・関連線・Floating 座標）は `.out` に保存される（非デフォルト値のみ、旧バージョンで開いても壊れない）。
