# Release 0.210.0

## ハイライト
- **起動時フラットレイアウト移行ゲート**: 旧レイアウトの note フォルダを開くと、本体を表示する前に移行画面が出て、共有フラットレイアウトへ安全に移行できます。
- **移行時のデータ損失を根絶**: cross-outliner 参照・本文 md リンクのみ到達する md・`<note>/pages/` 旧レイアウトの取りこぼしを修正。破壊的削除の前に「到達可能な全 md/画像/添付が移行済み」を保証。
- **自動バックアップ + 復旧導線**: 移行前に note フォルダを丸ごとバックアップし、場所と復旧手順を通知。

## 詳細な変更内容

### 新機能
- 旧レイアウト（per-`<stem>/` / `_notes_md/` / `<note>/pages/`）の note フォルダを開くと移行ゲートを表示。移行ボタンで共有フラットレイアウト（md=note 直下、画像/添付=共有 `images`/`files`）へ移行。移行後は再表示されない。
- 移行実行前に note フォルダ全体を外部へ自動バックアップ（backup 失敗時は移行中止）。移行完了後に backup 場所と復旧手順を通知。移行中エラーは自動巻き戻し。
- cross-outliner（別 outliner フォルダ）にある md・画像・添付を横断解決して移行。同名衝突は連番リネームで 1:1 所有を維持。
- 本文 md リンクの subpage 判定（同 outliner フォルダ内・node/note 未参照・本文リンクからのみ到達）と、到達可能な md の推移的移行。

### 修正
- 移行時に「参照されているのに移行されず旧フォルダごと削除される」データ損失を複数経路で根絶（cross-outliner / 本文リンク到達 / `<note>/pages/`）。実 note 3 件（tepco2 / pace2 / aws2）で検証し、到達可能な md の損失ゼロを確認。
- 到達不能な参照（実体がどこにも無い＝元々壊れ）のみ「参照先が見つからなかった項目」として通知し、旧フォルダは掃除。

## 移行ガイド
- 旧レイアウトの note を開くと自動でゲートが出ます。**移行前に対象フォルダをバックアップ**することを推奨（機能側でも自動バックアップしますが、二重の保険）。
- 移行後、旧サブフォルダ（`<stem>/` / `_notes_md/` / `pages/`）は削除され、note 直下がフラット構成（md + 共有 `images`/`files` + `.out` + `outline.note`）になります。
