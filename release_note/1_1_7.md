# Release 1.1.7

## ハイライト
- **cmd+click で新規タブ** — ファイルツリーと page アイコンから、開いている画面を潰さずに新規タブで開けるように
- **Outliner node の Export bundle** — node ツリー + 添付一式をフォルダに書き出し

## 詳細な変更内容

### 新機能

#### cmd+click 新規タブ
- note のファイルツリーで md / outliner を **cmd+click**（Windows/Linux は ctrl+click）→ webview 内タブで開く。通常 click は従来どおりメインペイン差替
- outliner の md ノードの 📄 page アイコンを **cmd+click** → page md を新規タブで開く
  - Notes モード: webview 内タブ
  - Single Outliner モード: VS Code タブ（fractal editor）
- 右クリックメニューの「Open in new tab」と同じ経路なので挙動は一貫

#### Export bundle（outliner node）
- node を右クリック →「Export bundle」（バンドルをエクスポート）→ 出力先フォルダ選択ダイアログ（Export here）
- 出力: 選択フォルダに `<nodeId>/` を作成し
  - `<nodeId>.md` — 対象 node + 子孫の md リスト（node リストを cmd+c → md に cmd+v した結果と同じ見た目。page は `[[title]](id.md)`、ファイルは `[📎 title](files/...)`）
  - page md の複製（本文が参照する画像・ファイルも複製 — 単体で完結する bundle）
  - `files/` — ファイル添付の複製
- node に直接付けた画像は出力対象外
- 同名フォルダがあれば `-1` サフィックスで回避。ダイアログをキャンセルすれば何も作られない
- Notes / Single Outliner 両モード対応

### セキュリティ
- Export bundle の出力フォルダ名（nodeId）をサニタイズ（外部由来 .out に細工された id が出力先の外へ書き込むのを遮断）
