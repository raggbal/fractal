# Release 0.209.7

## ハイライト
- **Mindmap Mode の検索が「発見型」に**: 検索ボックスの入力で該当ノードをハイライトし、順に画面中央へジャンプ（Outliner の絞り込みとは別方式）。
- **形状変更で自動的に中心へ**: layout（left/right/radial/balanced）を切り替えると、開いた直後と同じく title 中央ノードが画面中心に来る。
- **Mindmap 用にヘッダーを整理**: 使わないボタンをグレーアウトし、export ボタンを一旦撤去。
- すべて既存 FR-021 の挙動改善・UI 調整であり、breaking change なし（patch リリース）。

## 詳細な変更内容

### 新機能
- **[M] Mindmap 検索（発見型）**: 検索ボックスに文字を入力すると、テキスト（本文・サブテキスト）に一致するノードを黄色でハイライトし、最初の一致を画面中央へパンする。Enter を押すたびに次の一致へ順に巡回して中央化する。Outliner の検索（絞り込み）と異なり、ノードは全て表示されたまま目的のノードを「発見」する用途。Escape でハイライト解除。

### 改善
- **[G] 形状変更で中心化**: Cmd+Shift+L またはツールバーの layout 選択で mindmap の形を変えると、title 中央ノードを画面中心へ再配置する（開いた直後と同じ見え方）。
- **[K] ヘッダーの整理**: Mindmap Mode では使わないヘッダーボタン（タスクモード / タスクフィルタ / アーカイブ / メニュー / 戻る・進む / 検索モード切替）をグレーアウト（無効化）する。有効なのは undo / redo / ビュー切替 / S3 sync / 検索ボックス。Outliner / Table に戻すと元に戻る。
- **[L] ヘッダー機能の動作確認**: undo/redo（mindmap の編集履歴に連動）、ビュー切替（Outliner→Table→Mindmap の 3 循環）、S3 sync が Mindmap Mode でも動作することを確認。

### 修正
- **[I][J] Cmd+Enter で添付を開く**: Mindmap Mode で file 添付ノードの Cmd+Enter が外部アプリでファイルを開くようになった（Outliner と同じ挙動）。md（ページ）添付ノードの Cmd+Enter は従来どおり side panel の md エディタで開く。

### 削除
- **[H] エクスポートボタン撤去**: Mindmap Mode ツールバーの PNG / SVG / OPML / Markdown エクスポートボタンを削除（現時点で不要）。内部の書き出しハンドラは将来復活用に残置。
