# Release 0.210.18

## ハイライト
- **Notes webview 内マルチタブ**: Notes モードのメインペインで複数ファイル（Outliner / Markdown）をタブで開けるようになりました。~20 タブでもメモリ安全（unload/load 方式）。
- **サイドパネルがタブと共存**: サイドパネルを開いたままタブを切り替えられ、タブごとにサイドパネルの開閉・スクロールを復元。シャドー背景（overlay）は全モードで廃止し、外側クリックでは閉じません（Esc / ✗ で閉じる）。
- **タブ名が title/H1 に + 即時反映**: タブ名はファイル名でなく Outliner title / Markdown 先頭 H1 を表示し、編集すると即座にタブ名・Recent に反映されます。

## 詳細な変更内容

### 新機能
- **マルチタブ**（FR-TAB）: Tab Bar（2 タブ以上で表示）、新タブの 3 契機（openInNewTab / 本文リンク cmd+click / ＋ボタン）、タブ切替での状態復元（スクロール・サイドパネル）、✕ で閉じる（最後の 1 タブは残す）、Tab Bar 横スクロール、他 note / note 外 md のタブ表示。
- **タブ右クリック「Open in VS Code Tab」**: md タブを standalone エディタで開く。
- **md Outline の閉じるボタンを ✗ に**、note md で file panel トグルを Outline ヘッダ左へ移設。
- **Recent 履歴の記録拡張**: アプリ内リンク・他 note / note 外の md も Recent に記録。

### 改善
- サイドパネルの高さをタブ内領域に制約・タブと共存・per-tab 復元。
- タブの選択/非選択の背景色を反転（選択タブが editor と地続きに見える・下境界線を消す）。
- Recent クリックは page md も含め全てメインペインで開く（履歴 kind を note-md・絶対パスに統一）。

### 修正
- サイドパネル幅が editor 領域を超えるバグ（ResizeObserver で追従）。
- タブ復帰時のスライドインアニメ / スクロールのチラつき。
- outliner ヘッダーの検索状態がタブ復帰で消える問題（全モードで復元）。
- open-new-tab で開いた md の H1 編集がタブ名・Recent に即反映されないバグ（disk 書込 await + 3 保存経路の統一）。
