# Release 1.1.11

## ハイライト
- **note 間の node コピーで添付が複製されない重大バグを修正**（データ整合）

## 詳細な変更内容

### 修正
- **note A の node 群を cmd+c → note B に cmd+v したとき、2 個目以降の添付（page md・画像・ファイル）が複製されなかった**
  - 原因1（主因）: 内部クリップボード store が最初の複製処理後に消費され、以降の複製要求がすべて無言で無視されていた。cut では構造的に必ず発生する欠陥だった → 消費を廃止し、全 node の添付が確実に複製されるように
  - 原因2（副因）: クリップボード書き込みの失敗が握りつぶされ、OS クリップボードに残った過去の cut メタが copy 操作を cut と誤判定させていた → 書き込み失敗時のフォールバックを追加し、さらに host 側で copy/cut を突き合わせて矯正（誤判定を検出したら copy として処理し、page には新 id を発行 — 2 つの node が同じ page md を共有する事故を防止）
- cut（cmd+x）→ paste も同様に全添付が移動されるように
