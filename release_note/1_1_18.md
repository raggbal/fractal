# Release 1.1.18

## ハイライト
- **アプリ名が「Fractal Note」に**（設定キー・`fractal://` リンクはそのまま）
- **Copy in-App Link をどこからでも** — ファイルツリー右クリック / Outliner Menu / md ツールバー
- **cmd 長押しでショートカット一覧 HUD**（Markdown / Outliner / Mindmap / Database の 4 モード対応）
- **Note ツリー ⇄ エディタの md D&D を全面整備**（同一 note は移動・別 note は複製）

## 詳細な変更内容

### 新機能
- **Copy in-App Link の展開**: ファイルツリーの out/md 右クリック・Note Outliner ヘッダーの Menu・md エディタの Copy Path 右（Notes md 限定）に追加。クリップボードには `[タイトル](fractal://...)` 形式
- **fractal:// リンクの新形式**: outliner 全体を開く out link と、note md を開く md link を追加（既存の node/page link は不変・後方互換）
- **ショートカット HUD**: cmd（Windows は Ctrl）を 800ms 単独長押しでショートカット一覧をポップアップ表示。表示中のビューに応じて Markdown / Outliner / Mindmap / Database (Table) 用のリストとタイトルを自動で出し分け（sidepanel md 表示中は Markdown 用）。キーを離すと消える
- **外部 .md の D&D は subpage 登録に**: md エディタに .md をドロップすると、files/ 添付ではなく編集中 md の隣へ一意名でコピーし `[[タイトル]](file.md)` の subpage リンクを挿入（3 チャネル対応・画像/他拡張子は従来どおり）
- **Note ツリー ⇄ エディタの md D&D**:
  - ツリー md → Outliner: page ノード化（📄 アイコンから開ける）
  - ツリー md → md エディタ / sidepanel md: subpage リンク挿入
  - md 内の subpage アンカー（`[[...]]`）→ ツリー: ドラッグで登録（アイコンに grab カーソル・登録後は元 md からアンカー除去）
  - **同一 note 内はコピー・リネームせず移動（所有の移し替え）/ 別 note へ

は複製**
- **codeblock 折り返しトグル**: コードブロック右上の ↩ ボタンで折り返し表示を切替（ファイルには保存しない・全画面ポップアップにも引き継ぎ）

### 改善
- ファイルツリーの「+」ボタンを「+out」表記に（+md と対称）
- Copy in-App Link アイコンを水平リンクアイコンに差し替え（見切れ解消・全ボタン同一幅）
- Outliner の page md ドラッグは 📄 ページアイコン起点に（● bullet は並べ替え専用）

### 修正
- 新 md link のパストラバーサル防御（note フォルダ外を開けない・ADRL-0040）
- D&D 直後にツリーの item を 1 回クリックしても開かない問題
- Copy Path で貼り付けた .md パスのリンクアイコンが親 md 再読込まで表示されない問題

### セキュリティ
- fractal:// md link の id セグメントを decode 後に note フォルダ配下へ clamp（reviewer 指摘・counterfactual テストで固定）
