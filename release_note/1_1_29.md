# Release 1.1.29

## ハイライト

- **Header トグルの意味論を全面改訂**(v1.1.28 の headerless table 機能への即時フォローアップ): 「表示/非表示の切替」から「構造変換」へ

## 詳細な変更内容

### 変更(FR-TBL-01..03 rev2 / ADRL-0053 が ADRL-0052 を supersede)

- **ON** = table の一番上の通常行を header(th 行)に変換
- **OFF** = header を完全解除して通常行に変換(内容・整列は 1 行目の通常行として残る — 隠れない・消えない)
- **トグル状態** = 実 header 有無を反映(header ありなら「H」ボタンが accent 色で active 表示)
- **貼り付け** = header の無い HTML 表は真の headerless(th 行ゼロ)として貼り付く(隠れた空 header を持たない)
- md は GFM 互換を維持(マーカー + 空 placeholder header 行)。v1.1.28 形式(マーカー + 内容付き header)の md は、その内容が先頭の通常行として表示される(データ喪失なし)
