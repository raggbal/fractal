# Release 1.1.10

## ハイライト
- **リストの cmd+x（切り取り）まわりのバグを一掃**

## 詳細な変更内容

### 修正
- **空マーカー残り**: ネストリストを範囲選択して cmd+x すると空の •/○/▪ が残っていた → 選択で空になった行を自動掃除。画像やチェックボックス付きの行（選択外）は保全
- **cut→paste の構造崩れ**: 切り取ったネストリストを別リストの空行に貼ると、先頭行がリスト外に落ち階層がリセットされていた → 貼り付け先の階層に相対ネストごと接ぎ木されるように（リンクも維持）
- **タスク行の cut で checkbox 殻が残る**: テキストを全選択して cmd+x すると checkbox だけの行が残っていた → 行ごと消えるように（部分選択なら checkbox は残る）
- **cut→cmd+z で checkbox 消失（約50%）**: cut だけ undo 記録が無く、タイミング依存で古い状態に戻っていた → cut 前の状態を確実に記録し常に正しく戻るように
