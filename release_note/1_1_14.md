# Release 1.1.14

3 つの sprint の成果をまとめたリリースです（Export bundle 複数選択 / outliner D&D の信頼性 / D&D indent インジケータ + リスト修正）。

## ハイライト

### 1. 複数 node の Export bundle（outliner）

複数 node を選択して右クリック → Export bundle で、選択した全 node が 1 つの md に出力されます。各 node の添付（画像・ファイル・page md）もすべて bundle に含まれます。

- 親子を跨いだ選択も OK（重複なく出力・copy/cut と同じ扱い）
- 選択なしの右クリックは従来どおりその node + 子孫だけ

### 2. D&D 挿入インジケータの indent 対応（outliner）

node の並べ替えや外部ファイルの drop で、挿入線が**落ちる先の階層の bullet 位置**から描かれます。indent の違う node の間でも「どの親の子になるか」が一目で分かり、**マウスを左右に動かすと挿入先の階層を選べます**（ファイルツリーと同じ操作感）。

- 子にしたいとき: node 本体に重ねる → 青点線囲み → drop（従来どおり）
- 線どおりの場所に必ず入ります（表示と挿入は同じ計算を共有）

### 3. D&D の信頼性修正（outliner）

- shift を押さずに D&D しようとして水色枠が残るバグを修正（どんな終わり方でも枠とインジケータを掃除）
- shift+D&D でファイル添付 node が作られないことがある問題を修正（node のテキスト部分への drop の取りこぼし解消 + 環境依存の判定フォールバック）

### 4. .drawio の D&D 受理（md エディタ）

素の .drawio ファイルを「drawio Desktop で変換してください」と弾かず、他のファイルと同じ添付リンク `[📎 xxx.drawio]()` として取り込みます（outliner と同じ挙動に統一）。`.drawio.svg/.png` の画像表示 + drawio Desktop 連携は従来どおりです。

## 修正
