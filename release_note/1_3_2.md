# Release 1.3.2

## ハイライト

- **sidepanel md への paste が note md にも二重貼付されるバグを修正**（destination 札の配線拡張）
- **`$$...$$` display math 対応 + 数式内 CJK/ハングルのレンダリング修正**（KaTeX strict:false + フォント fallback、PDF 出力含む）
- **複製/コピー系メニューの大幅拡充** — md リンク・outliner node・tree item の Duplicate（実体複製・subpage 再帰）、Copy Path 系の追加・改名、copy subtree の複数選択対応

## 詳細な変更内容

### 新機能

- **$$ display math ブロック**: `$$...$$`（1 行 / 複数行）を KaTeX でレンダリング。Typora/Obsidian 互換。serialize は `$$` 形式を byte 保持し ```math とは相互変換しない。```math 内に `$$` を書いても表示時に剥がして正しく描画
- **md editor リンク右クリック**: Copy Path（subpage/file は絶対パス・通常リンクは URL）/ Duplicate（subpage・file リンク — 実体複製して直下に複製リンク挿入・1 undo）/ Copy (file link full path)（メニュー全域 — 選択範囲内の subpage/file/md リンク URL を絶対パス化してコピー）
- **outliner node 右クリック**: Copy Path 新設（page→md パス / file→添付パス・複数選択は 1 行ずつ）/ Copy File Path の複数選択対応 / Copy Page Path → **Copy Md Path** 改名 / copy subtree as xxx 3 種の**複数 node 選択対応**（forest 出力・祖先包含は重複排除）/ **Duplicate**（cmd+c→cmd+v と同一意味論・内部クリップボード非破壊）
- **note file tree**: ヘッダ **+file** ボタン（ダイアログで外部ファイル登録）/ 右クリックに **New link folder**（全分岐）/ out・md・file item の **Duplicate** — 複製は元と資産を一切共有せず、**md が参照する subpage/file/image は再帰的に複製**（循環 subpage も安全に打ち切り。参照リンク `[label](x.md)` は共有のまま）

### 修正

- note md から開いた sidepanel md への貼り付け（outliner node 貼付・画像入り HTML 貼付）が **main 側の note md にも二重適用**される問題
- **ハングル・アクセント付き Latin・半角カナ見出しの TOC アンカーが空になり**ジャンプできない問題（アンカー生成 4 箇所を Unicode 対応・既存の英数/日本語アンカーは互換維持）
- **wholeWord 検索が CJK クエリで全滅**する問題（検索の単語境界を webview・host・CLI で共通モジュール化）
- notes タブ右クリックメニューが英語固定だった問題（7 locale 対応）
- 数式内の CJK/ハングルが警告色になる・フォントサイズが不揃いになる問題（strict:false + `.cjk_fallback`/`.hangul_fallback` CSS、PDF エクスポートにも適用）

## 既知の制限

- インライン数式 `$...$` は未対応（display block のみ）
- cross-outliner の pending クリップボードは node Duplicate 後に復元されない（既存 store-mismatch と同型の縮退・受容済み）
