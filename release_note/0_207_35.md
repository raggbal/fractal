# Release v0.207.35 — translate-ux-and-outliner-polish

> Sprint: `20260510-140531-translate-ux-and-outliner-polish`
> 累積 patches: v0.207.4 〜 v0.207.35 (32 patches、2026-05-10 ship)

## ハイライト

1. **🌐 翻訳機能 UX 刷新** — 言語選択 + 翻訳実行を 1 button popup に統合、翻訳結果を outliner の親 node の子 page として保存可能に、AWS Translate Custom Terminology (CSV/TMX) 対応、コードブロック等は翻訳経路から完全分離
2. **⌨️ `Cmd+\\` 右サイドパネル toggle shortcut** — Notes 左 file panel / MD outline TOC を context-aware に開閉、sidepanel 内 focus 時は内側 TOC のみで波及防止
3. **🎨 Teal-blue primary palette** — 旧 royal blue を穏やかな teal-blue に、tag/link 文字色は `--fr-color-primary-strong` (`#3994BC`) で読みやすさ確保
4. **🎯 Cursor 行 highlight** — outliner で cursor 行を全列同色 highlight、table view では outline + text + multiselect + date 列**全て**同期

## 詳細な変更内容

### 新機能

#### 翻訳 (FR-TR-01〜04)
- **翻訳 popup 統合**: standalone toolbar / sidepanel header の翻訳ボタンを 1 button + popup に統合 (source/target select + Execute、ESC/outside で close)
- **翻訳結果を outliner に保存**: sidepanel の翻訳結果 view に「翻訳結果を保存」 button、click で H1 抽出 → 親 outliner node の子 node + 新 page MD として attach
- **AWS Translate Custom Terminology**: `fractal.translateTerminologyFile` (絶対 / `~/...` / 相対 path) + `fractal.translateTerminologyName` 設定。CSV / TMX 自動判定。Tools tab に「Update Translate Terminology」 button + `fractal.updateTranslateTerminology` command
- **コードブロック翻訳保護**: fenced code (` ```...``` `) / inline code (` `...` `) / block math (`$$...$$`) / HTML comment (`<!--...-->`) は AWS Translate に送らずそのまま結果に含める。segment 分離方式で確実

#### Cursor 行 highlight (FR-OL-CR-01)
- outliner で cursor のある行を全列 highlight (淡 teal `#DEEDF5`)
- table mode: outline + text + multiselect + date / datetime 列**全て**が同色同期
- 範囲選択 (`is-selected`) は引き続き orange tint で別色識別

#### Cmd+\\ Shortcut (FR-KB-01)
- Mac: `Cmd+\\` / Win/Linux: `Ctrl+\\`
- **Standalone MD editor**: 主 sidebar (Outline TOC) を toggle
- **Notes editor 主 outliner**: **左 file panel** (notes / search / tools) を toggle
- **Sidepanel MD active** (notes / standalone outliner 内): 内側 outline TOC のみ toggle、外側パネルは触らない
- 関連 button title (hover tooltip) に `(Cmd+\\)` 併記

### 改善

#### Outliner editor visual polish (FR-OL-VP-01〜11)
- outliner content theme bug 修正 (`@layer fr-legacy` ラップ + layer order 統一)
- tokens.css に `--outliner-*` legacy alias 23 個追加
- bg-app / bg-panel 統一 (`#FAFAF7` light / `#1E1F28` dark)
- 列ヘッダー透過排除 (opacity → `--fr-color-text-secondary`)
- 列リサイズ handle 2px 統一 + center alignment
- selection bar 2px 統一
- outliner editor の hover 反転を全削除 (dead code 除去)
- file-panel-item active + hover specificity 修正
- outliner-text 系 focus 装飾排除 (transparent/none)
- date cell visual + Cmd+arrow 移動対応
- multiselect popup keyboard nav (↓↑Enter + `is-highlighted`) + simulated text caret

#### Visual: Teal-blue palette (FR-VP-PRI-01/02、FR-VP-BAR-01)
- `--fr-color-primary` を `#9CC8DC` (淡 teal) に
- 新 token `--fr-color-primary-strong` (`#3994BC` 濃い teal、tag/link 文字色用)
- `--fr-color-primary-soft` を `#DEEDF5` に
- 「ノート」タブ underline + file panel item active 縦バー: 2px → **1px**
- dark mode は `#7DC4DF` 系で揃え

### 修正

- 翻訳結果保存で新 node が outliner に出ない真因 (`childIds` → `children` field 名修正、v0.207.29)
- Notes mode の `Cmd+\\` が VSCode に intercept されて動作しない件 (v0.207.34、keybinding 経路に切替で解消)

### 撤廃

- `fractal.outlinerImageDefaultDir` / `fractal.outlinerFileDir` / `fractal.outlinerPageDir` (convention + legacy fallback に統一)
- `fractal.linkOpenMode` (常に tab 動作)

### 設定 default 変更

- `fractal.toolbarMode` の default を `"simple"` に

## 移行ガイド

### 撤廃された設定

ユーザー `settings.json` に以下が残っていても無害 (provider 側で読まずに無視):
```json
"fractal.outlinerImageDefaultDir": ...,
"fractal.outlinerFileDir": ...,
"fractal.outlinerPageDir": ...,
"fractal.linkOpenMode": ...
```

### 新規設定 (任意)

```jsonc
// AWS Translate Custom Terminology (任意)
"fractal.translateTerminologyFile": "/Users/<user>/translate/terminology.csv",
"fractal.translateTerminologyName": "my-terms"
```

CSV 形式例 (1 行目は言語コード):
```csv
en,ja
EC2,EC2
Lambda,Lambda
```
