# Release 1.3.10

## ハイライト

- **全 file viewer（PDF / Word / Excel / PowerPoint / HTML / text / 画像）でトラックパッドのピンチ拡大縮小に対応** — VS Code 全体が拡大してしまう問題を解消
- **[−][+] ズームボタンを全 kind に拡大**（従来は PDF / 画像 / PowerPoint のみ）
- **PDF のドラッグパン** — 拡大して見切れた部分をドラッグで移動して閲覧できる

## 詳細な変更内容

### 新機能

**ピンチズーム統一（FR-VZP-01 / ADRL-0100）**

- viewer 領域上の (Ctrl/Cmd)+スクロール（トラックパッドのピンチは Chromium でこの形で届く）をカーソル位置を不動点として viewer コンテンツの拡縮に変換
- 同時に preventDefault することで、**viewer 上のピンチで VS Code（Electron）全体がズームしてしまう挙動を抑止**（viewer 外は従来どおり）
- 係数は mindmap で実機チューニング済みの連続式を全 kind で共通化（複製箇所は一致番人テストで保護）
- HTML viewer は sandbox iframe 内にイベントが閉じるため、注入ヘルパが iframe 内で同処理（抑止漏れなし）。倍率はスクリプト許可トグルの再描画をまたいで維持

**[−][+] ボタンの全 kind 化（FR-VZP-02）**

- Word: 自動フィット倍率へのユーザー倍率乗算 / text: フォントサイズ倍率 / Excel: **グリッド geometry の再構築**（行高・列幅・フォントに倍率を織り込む — CSS zoom 非依存で古い Chromium ベースの VS Code フォークでも動作）/ HTML: iframe 内 zoom
- 倍率クランプ: 新設 4 kind は 0.25×–8×、既存 clamp を持つ kind（PDF / PowerPoint / 画像）は既存値を維持（FR-VZP-05）

**PDF ドラッグパン（FR-VZP-03）**

- ズーム等であふれている時、ページの余白・画像部分からのドラッグでパン（カーソルは grab/grabbing）
- **テキスト選択と共存**: テキスト行（span 単位）やリンク注釈の上から始めたドラッグは従来どおり選択/リンク動作。3px 未満の移動は click 扱い。**中ボタンドラッグはどこからでも常にパン**

### 変更なし（明文化）

- 画像 viewer の「Ctrl 不要の無条件ホイールズーム」は既存仕様として維持（FR-VZP-04）
- ズーム倍率の永続化はスコープ外（タブ再オープンでリセット = 従来どおり）
- PDF の幅追従再フィット（v1.3.9）は手動ズーム後に停止する契約のまま — ピンチズームも「手動ズーム」として同様に refit を停止させる（整合確認済み）
