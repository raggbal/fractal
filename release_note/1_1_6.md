# Release 1.1.6

## ハイライト

1. **Outliner のノードリストを md に貼ると添付ごと付いてくる** — page md は subpage リンク、ファイルは 📎 リンクとして複製
2. **ファイルツリー D&D の大幅改善** — 兄弟ドロップの 3 ゾーン化・谷間での不発解消・インデントによる階層選択

## 詳細

### 新機能: node リスト paste の添付複製
- outliner で cmd+c → md editor（note md / sidepanel md / standalone）に cmd+v:
  - page md 付き node → `[[タイトル]](<id>.md)` subpage リンク + md 実体を対象 md と同フォルダに複製（参照画像も再帰複製）
  - ファイル添付 node → `[📎 タイトル](files/...)` + 実体複製
  - 行はリンクのみのすっきり表示（nodetext の繰り返しなし）
  - 添付なしのリストは従来どおり

### 修正: ファイルツリー D&D
- md → outliner: 上 25%=兄 / 中央=取り込み / 下 25%=弟 の 3 ゾーン
- 「線は出るのにドロップ失敗」（item 間の谷間）を解消 — 線が出ていれば必ずその位置に drop
- ネスト末尾での「親の後ろ」: マウスの横位置で階層を選択（線が B の幅 ⇄ D のインデントで切替）
- 「子が丸ごと選択される」分かりづらい中間状態を廃止
