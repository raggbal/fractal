# Release 1.1.19

## ハイライト
- **数字リストの番号が「Word のように」自動で揃うようになりました**（先頭だけ番号指定可・あとは自動連番）
- **ファイルツリーに外部の markdown を D&D で取り込み**
- **ネストした数字リストの表示が 1,2,3 → a,b,c → ⅰ,ⅱ,ⅲ の循環フォーマットに**

## 詳細な変更内容

### 新機能
- **ツリーへの外部 md D&D**: Finder / エクスプローラから .md をファイルツリーの任意の位置（項目の間・フォルダ内・ルート）にドロップすると、新規ファイルとして複製・登録されます（タイトルは先頭 H1）。md 以外のファイルはスキップされます（ファイル添付のツリー対応は次フェーズ予定）
- **ネスト深さ別の数字リストマーカー**: 深さに応じて 1,2,3 → a,b,c → ⅰ,ⅱ,ⅲ を循環表示（9 段まで明示・PDF エクスポートにも適用）。**md ファイルの中身は `1. 2. 3.` のまま**なので他エディタとの互換性は変わりません

### 数字リストの意味論を刷新（ADRL-0042）
番号の扱いを 3 原則に統一しました:
1. **番号の手入力が意味を持つのは連なりの先頭だけ** — bullet 行や段落の行頭で「7. 」と打つと（前に数字リストが無ければ）7 から始まるリストに。どの階層でも有効
2. **隣接した数字リスト同士は常に結合して自動連番** — 間の bullet を消す・Tab でインデントする・範囲削除するなど、どの操作で隣接しても同じ
3. **間に何かが挟まる分割は番号を保持** — 途中を bullet 化・Enter でリストを抜ける等では前後の表示番号が変わりません

また、空の数字行でも backspace の 1 回目は bullet 化（2 段階）になり、値あり行と挙動が揃いました。

### 修正
- ツールバー / Ctrl+Shift+U で数字リストの途中を bullet 化すると番号が 1. にリセットされる
- bullet 行の行頭で「2. 」等と打っても番号が無視される
- **混在リスト（bullet + 数字）の貼り付けで階層が崩れる**（4 スペース以上のインデントで数字リストが bullet の子に潜り込む積年のバグ。ネスト判定をインデント実測値ベースに全面修正）
- 数字リスト間の空 bullet を削除した際にカーソルが誤った行へ移動する
