# Release 1.1.31

## ハイライト
- **mindmap の操作パリティ**: cmd+c/x/v(子孫込み・outliner と同じ資産契約)・画像の選択削除・md/file の D&D 4 経路・アイコン click で開く
- **outliner 画像 paste の二重貼付を根治**

## 詳細な変更内容

### 新機能(mindmap)
- cmd+c/x = フォーカス node + 全子孫を copy/cut、cmd+v = フォーカス node の子として貼付(同一 note: c=複製/x=流用、cross-note: 常に複製 — outliner と同一契約)
- 画像 click 選択(accent 枠)→ Delete 削除・undo 可
- 📄/📎 アイコン: click で page/添付を開く・note tree / markdown editor(main/sidepanel)へ D&D 可。tree・md editor からの md/file D&D も受け付け(位置 = node の子)

### 修正
- outliner 画像 paste 二重貼付(stale mindmap listener・bridge listener 累積・バブリングの 3 機序を全封鎖)
- 選択画像の視覚識別(outline + shadow)+ 他所 click で解除
- md からの D&D 取込で元リンクが残る(host が fs で直接除去 — 単一真実化)
- **mindmap への drop で画面が飛ぶ**(zoom/pan を保存・復元)
