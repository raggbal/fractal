# Release 1.3.18

## ハイライト

- **背景が画像の pptx スライドが描画されるようになった** — スライド・レイアウト・マスターのどこに画像背景があっても表示される（以前は真っ白になり、白文字が見えなかった）
- **pptx のテキストが枠で切れなくなった** — 枠より高いテキスト（1 行分の枠に 2 行のタイトル等）も、PowerPoint と同じく枠からはみ出して描く

## 詳細な変更内容

### 修正

**pptx の画像背景**
- 背景画像の読み取りがパーサの出力の形と合っておらず、常に「背景なし」になっていた。slide / layout / master の 3 階層とも描画する
- 背景画像の透過（alphaModFix）は背景だけに効き、スライドの文字や図形は透過しない

**pptx のテキストの見切れ**
- 枠より高いテキストは、縦位置の揃えに合わせてはみ出す（上揃え = 下へ / 中央 = 上下へ / 下揃え = 上へ）。スライドの外は従来どおり描かない
- 以前は、溢れた段落の高さが押し縮められて行が重なり、下の行が切れていた
- 自動縮小（normAutofit）は、上方向にはみ出す場合も正しく縮小する

**フォントが無いときの折り返し位置**
- 「Amazon Ember Display」「Segoe UI Semibold」「游ゴシック Light」のように太さ・用途の語が付いたフォントが無い環境では、同じファミリーの基本名（Amazon Ember / Segoe UI / 游ゴシック）を次の候補にする。字幅が近くなり、折り返し位置のずれが減る（完全一致はしない）
- 文書のフォント名に `"` や `\` が含まれていても、文字のスタイルが崩れない

### 内部

- v1.3.16 のフォルダ D&D の仕様（フォルダも運ぶ・転送中は次の drop を受けない）に追いついていなかったテスト 6 件を現仕様に更新（アプリの挙動は不変）
