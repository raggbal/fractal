# Release 1.1.1

## ハイライト

1. **Chrome 拡張が英語対応**（デフォルト英語・Settings で日本語切替）
2. **AI Skills の検索が大幅強化**（note 一覧 / 名前検索 / md 先頭 H1 検索 / AND 組み合わせ）
3. **AI Skills の symlink 実行バグ修正**（`~/.claude/skills` 経由の CLI が無反応だった問題）

## 詳細な変更内容

### Chrome 拡張 v0.4.0 — i18n

- 新規インストール時は英語 UI。Settings（options ページ）の Language セレクタで日本語に切替
  （`chrome.storage.local` に永続化。popup は選択言語に追従表示）
- 対象: popup / options / 通知（quick clip 含む）/ エラーメッセージ / クリップ生成 md の
  メタラベル（Source / Author / Site ⇄ 元ページ / 著者 / サイト）

### AI Skills — fractal-search 検索強化

- `--list-notes` / `--list-folders` × `--note-name`: note の一覧取得と note 名/フォルダ名検索
- `--outline-name <str>`: outliner 名で検索（単独 = 一覧、他フィルタと AND 合成可）
- `--h1 <str>`: md の先頭 H1 で検索（CommonMark 準拠 — `# C#` の末尾 `#` を保持、
  コードフェンス内の `#` を誤検出しない）
- すべて AND 合成可: 例 `--note-name 仕事 --outline-name 計画 --h1 2026 --query 納期 --json`
- Claude Code / Cursor / Kiro / Antigravity のどのエージェントからでも利用可

### 修正

- **symlink 配置（claude/cursor/antigravity）の全 fractal 系 skill CLI が無反応になるバグ**:
  import guard が Node の realpath 解決と不一致だった。6 スクリプト全てを修正
- fractal-md.mjs の H1 抽出（md 取り込み時のタイトル導出）がコードフェンス内 `#` を誤検出する問題

### VS Code 拡張本体

- 変更なし（バージョン同期のみ）
