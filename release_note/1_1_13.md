# Release 1.1.13

## ハイライト

md エディタのリスト操作 2 件を使いやすくしました。

### 1. opt+enter の「折り返し子ノード」

リスト項目の**途中**にカーソルを置いて opt+enter すると、カーソル以降が子ノードに折り返されます。

```
- aaaa|bbbbb   （| = カーソル）
↓ opt+enter
- aaaa
  - |bbbbb     （カーソルは子の先頭）
```

- リンク・太字・文字色・画像を跨いで分割しても壊れません
- 行末で opt+enter したときは従来どおり空の子ができます

### 2. 数字リスト行頭 backspace の 2 段階化

数字リストの行頭で backspace すると、いきなり上の行に結合されるのではなく、まず**通常のバレットに格下げ**されます（タスクリストのチェックボックスが外れるのと同じ抜け方）。もう一度 backspace で従来どおり結合します。

```
1. a
2. |b     ← backspace 1 回目
3. c
↓
1. a
- |b      ← b はバレットに。c は 3. のまま（番号維持）
3. c
```

ネストした数字リストでも同じ挙動です。

## 修正

- **リスト型変換で以降の番号が 1 に化ける既往バグを修正** — 数字リストの途中の行を `- ` で型変換すると以降の表示番号が 1 起点に振り直されていた問題を、分割後リストへの開始番号引き継ぎで解消（v1.1.12 の開始番号保持と一貫）
