# Release 1.1.12

## ハイライト

**数字リストの開始番号が保持されるようになりました（CommonMark 準拠）。**

これまで md エディタの数字リストは、保存・編集のたびに必ず 1 から振り直されていました。そのため「1. a / 2. b / （段落） / 3. c / 4. d」のように段落を挟んで番号を続けたくても、2 個目のリストが常に「1. c / 2. d」に戻ってしまっていました。

本リリースから、CommonMark と同じ「先頭項目の番号がリストの開始番号を決める」ルールで動きます。

## 詳細な変更内容

### 新機能

- **md で「3. c」と書けば 3 から始まるリストになる** — 段落を挟んで分断されたリストの続きが書ける。表示・保存（round-trip）とも番号を保持
- **「4.」+ space のオートフォーマットで 4 起点のリストが始まる** — Enter で 5, 6, … と続く
- **外部 HTML の `<ol start="5">` を paste しても 5 起点で入る**（従来から対応していた paste 変換と内部エディタの動作が対称に）
- **開始番号の異なる隣接リストは無言統合されない** — 「1. a」の直後に「5.」と打てば独立した 5 起点リストができる（「2.」なら従来どおり続きとして統合）。段落→リスト変換（Ctrl+Shift+O）でも同じ保護が効く

### 仕様メモ

- 1 始まりのリストは DOM・md 出力とも従来と完全同一（`start` 属性は付かない）
- 2 個目以降の飛び番（3. / 7. / 9.）は先頭起点の連番（3. / 4. / 5.）に正規化される — 先頭のみが真実
- 開始番号は 1〜9 桁の正整数のみ有効（CommonMark 準拠）。不正値は従来どおり 1 起点
- undo/redo・cut・差分更新・タブ切替でも開始番号は保持
