# Release 0.209.14

## ハイライト
- **Outliner 間コピーでリンク先 md も再帰複製**: md 付きノードを別 Outliner に cmd+c / cmd+v したとき、その md が参照する自 Note 内の別 md（さらにその md 内の画像・添付）も再帰的に複製するようになった。

## 詳細な変更内容

### 新機能
- **md-to-md リンクの再帰複製**: 貼り付ける md の本文リンクを BFS で辿り、自 Note 内（`isUnderNoteDir` 判定）に実在する md を closure として収集して複製する。循環リンク（A→B→A）は visited 集合で検出し無限ループしない。
- **外部 Note リンクの扱い**: 自 Note 外の md リンクは複製せず、貼り付け先からの**相対パス**に書き換えて維持する（絶対パス化しない＝別 PC / S3 sync 後も可搬）。

### 修正
- **部分文字列誤置換バグ（HIGH）**: リンク URL の書き換えを「本文中のリンク URL 全体」を単位に行うようにし、`note.md` の改名が `mynote.md` を巻き込む部分文字列誤置換を根絶。

## 移行ガイド
- breaking change なし。挙動の追加のみ。
