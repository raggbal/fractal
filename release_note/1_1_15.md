# Release 1.1.15

## ハイライト
- **md → PDF エクスポート**（新機能）— md をきれいな PDF に。改ページは CSS で制御可能、デフォルトは章立てに沿った自然な改ページ
- **D&D 挿入線の左右反応を改善** — outliner と note ファイルツリーで、マウスの左右移動だけで挿入先の階層がスムーズに変わるように

## 詳細な変更内容

### 新機能: PDF エクスポート
- **起動**: コマンドパレット `Fractal: Export to PDF`、または md editor の toolbar / sidepanel header の PDF ボタン（Export bundle の左）
- **対象**: standalone md / Notes の md タブ / sidepanel の md（Notes・Single Outliner）。sidepanel のボタンは sidepanel の md を確実に対象にする
- **見た目**: エディタ表示と同じレンダリング結果を PDF 化（mermaid 図・KaTeX 数式・文字色・チェックボックス・画像込み）。印刷向けクリーンスタイル（A4・白背景）を同梱
- **デフォルト改ページ**: h1 と h2 の前で改ページ。ただし「最初の h1 の前」と「各 h1 直後の最初の h2 の前」には入れない（章扉の直後に空ページや無駄な改ページが出ない）
- **CSS カスタマイズ**: `fractal.pdfStyles`（CSS ファイルパスの配列）でデザイン・改ページ規則を上書き。`fractal.pdfIncludeDefaultStyles: false` で完全差し替えも可能
  ```jsonc
  "fractal.pdfStyles": ["~/fractal-pdf.css"],
  "fractal.pdfIncludeDefaultStyles": true
  ```
  ```css
  /* 例: 改ページを全部やめる */
  h1, h2 { break-before: auto; page-break-before: auto; }
  ```
- **仕組み**: ローカルの Chrome / Edge を利用して生成（拡張への依存追加ゼロ・VSIX サイズ増ほぼなし）。生成プロセスは外部通信を全遮断（Local-first）。ブラウザ未検出時はガイドを表示、`fractal.pdfBrowserPath` で実行ファイルの明示指定も可
- **安全設計**: エクスポートは read-only（md 本文・undo 履歴・エディタ状態を一切変更しない）。キャンセル時は副作用ゼロ・一時ファイル残留なし

### 改善: D&D 挿入線の左右反応
- outliner の node 境界と note 左サイドのファイルツリー（フォルダ境界）で、挿入線の階層選択（マウスの水平位置で線の長さが変わる）の判定帯を行の下端 25% → 40% に拡大
- 従来は左右に動かしても反応せず、少し上下に動かして初めて変わることが多かった → 純粋な左右移動でスムーズに変わるように
- node 中央への child drop（青点線囲み）・上端の before 判定は従来どおり
