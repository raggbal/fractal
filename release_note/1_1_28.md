# Release 1.1.28

## ハイライト

- **Headerless table** — table toolbar の「Header」トグルで header 行なしの表を作成・復元できます。header の無い HTML 表の貼り付け(Web / Excel)も headerless のまま貼り付きます
- **リスト継続行の中に引用・コードブロック** — Shift+Enter の継続行内で `> ` / ` ``` ` / Cmd+/ / toolbar / Ctrl+Shift+Q/K からブロックを作成でき、矢印・Enter・Backspace・コピー・Cmd+Z まで含む編集契約を整備しました
- **Cmd+Z のカーソル安定化** — リスト内ブロック周辺の undo でカーソルが下の行に飛ぶ・コードブロックに入らない・リストが吸い込まれる、といった一連のバグを根治しました

## 詳細な変更内容

### 新機能

- **FR-TBL-01/02/03: headerless table**(ADRL-0052)
  - Header OFF: th 行を非表示化(セル内容・列幅・整列は温存。ON で無劣化復元)
  - Header ON(paste 由来の空 header 表): 1 行目を header に昇格
  - md 永続表現は `<!-- fractal-headerless-table -->` マーカー + header 行温存。外部エディタ(GitHub / Obsidian)では通常の GFM table として表示(graceful degradation)
  - 貼り付け判定は turndown-plugin-gfm `isHeadingRow` 正典。heading row の無い表は headerless で貼り付く
- **FR-LC-05..08: リスト継続行内ブロック**
  - 作成 4 経路(autoformat / palette / toolbar / ショートカット)すべてが li 内ネストで生成(従来の「リスト全体が blockquote に置換される」破壊的挙動も修正)
  - md 往復: マーカー幅インデントで serialize、継続行分岐内で parse(ブロックなしリストの出力は 1 バイト不変)
  - 編集契約: 1 li に複数ブロック / ↑↓ でブロック進入・脱出(隣接画像含む) / ブロック内 Shift+Enter = 直後に継続行 / Backspace は行モデル整合(親リストへの統合は全ケース遮断) / 継続行アイテムのコピー & ペースト保全

### 修正

- **FR-TBL-04**: Excel 範囲コピー貼り付けで表の最後のセルにスクリーンショット画像が混入(Kiro 経路の `hasRichHtmlContent` ガード欠落)
- **FR-CB-01**: 空コードブロックの Enter 連打で改行が不可逆に蓄積 → Backspace で 1 個ずつ戻る対称挙動に。保存 md の改行純増も解消
- **FR-QB-01**: 完全に空の引用ブロックが Backspace で消せない → コードブロックと対称の段落化脱出(img / checkbox のみの引用は保護)
- **FR-TBL-05**: Ctrl+T が未定義関数を呼び silent fail → toolbar と同一経路に配線
- **undo カーソル安定化**(再オープン⑩〜⑭で 9 機序を根治):
  - snapshot を beforeinput 時点の {markdown, cursor} 同時点ペアで取得(不整合ペアの解消)
  - snapshot 時に常に live DOM を serialize(rAF 遅延の stale markdown 排除)
  - カーソル offset から UI 装飾テキスト(code-block-header 等)を除外
  - pre / blockquote 内部への復元は「ブロック index + 内部 offset」優先
  - ブロック直前の(描画に現れない)`<br>` を保存 / 復元で対称スキップ
  - 「> 」タイプ途中の素の `>` を空引用ブロックと誤解釈しない(空白必須化)
- **FR-KH-01**: Kiro の Cmd 長押し HUD — `isKiroEnv()` seam 化のうえ実機検収で動作確認(旧ビルドのインストールが原因の報告と判明・コード上は no-op 決着)

### 互換性

- 対象外形状(header あり table / ブロックなし li / 非空コードブロック)の serialize 出力は byte 不変
- 非 Kiro(VS Code)経路の挙動不変
- 新規 UI 文言(`tableToggleHeader`)は 7 locale 登録済み
