# Release 1.3.0

## ハイライト

- **内蔵ファイルビューア（HTML & PDF）**: AI が作るドキュメントは md だけでなく HTML も増えています。添付の `.html` / `.pdf` を、ファイルツリー・アウトライナーの 📎 ノード・マークダウンの 📎 リンクのどこからクリックしても、Fractal Note の中でそのまま読めるようになりました
- **3 つの表示面**: note のメインペイン（タブとして）・書きながら参照できるサイドパネル・独立した VS Code タブ。Open in new tab は notes のタブに開き、Open in Standalone で VS Code タブにも出せます
- **フルテキスト検索の拡張**: PDF / Word / Excel / PowerPoint に加えて、HTML・JSON・CSV・ソースコードなど**テキスト系ファイル全般**の中身も検索対象に

## 詳細な変更内容

### 内蔵ファイルビューア

- ツールバーは md サイドパネルと同じアイコン・並び（OS で開く / Open in Standalone / Export / パスコピー / アプリ内リンク / Open in new tab）。文言は 7 言語対応
- HTML: 既定で静的表示のままコピー可能（cmd+C / cmd+A）。ページ内スクリプトは「スクリプトを許可」を押した時だけ実行（ファイル単位・非永続）。防御の実体は CSP nonce で、sandbox に allow-same-origin は決して付きません
- PDF: ローカル pdf.js レンダで滑らかなドラッグ文字選択。cmd+A は PDF 内だけを選択
- サイドパネル: タブに重ならない配置・⤢ 最大化・左端ドラッグで幅変更・Esc で閉じると**書いていた場所にカーソルが戻る**
- tree file への In-App リンク `fractal://note/{folder}/file/{fileId}` を追加（Copy In-App Link から）
- **表示速度を何より優先**を絶対ルール化（初回表示の経路にブロッキング処理を置かない — 全フォーマット共通）

### セキュリティ

- viewer の pdf.js は既知の High 脆弱性（GHSA-hq66-cqwq-w95j — 悪意ある PDF で任意 JS 実行）の範囲外である **5.5.207** に明示固定（npm audit 0 件。検索機能側の 4.10.38 固定は不変）
