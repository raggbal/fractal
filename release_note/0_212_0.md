# Release 0.212.0

## ハイライト
- **standalone md の保存先を指定できる**: fractal note の外にある `.md` を単体で開いたとき、画像や添付ファイルの保存先フォルダを選べるようになりました。設定はそのフォルダの隠しファイル `.fractal.json` に記録され、**md 本文には一切書き込まないので Typora など他のエディタで開いても何も表示されません**。
- **左ファイルツリーの右クリックに「Open in new tab」**: md も outliner も、ノートの左ツリーから新しいタブで開けます。
- **設定の整理**: 使われていなかった/紛らわしかった 5 つの設定を削除しました。

## 詳細な変更内容

### 新機能
- **standalone md の画像/添付保存先（FR-MD）**
  - fractal note 配下**でない** `.md` を Fractal で開くと、アウトラインパネル最下部の「画像保存先 / ファイル保存先」表示がクリックできます。
  - クリック → 「フォルダを選ぶ」でフォルダを選択すると、md と同じフォルダの `.fractal.json`（`{"imageDir": "...", "fileDir": "..."}`）に保存先が記録されます。
  - **そのフォルダの全 md が同じ保存先を共有**します。md 本文は変更しないので、他のエディタ・プレビューに設定が漏れません。
  - 「デフォルトに戻す」で `<md と同じフォルダ>/images` `/files` に戻ります。
  - Notes 内 md / .out / outliner ページ md では従来どおり保存先は固定です。
- **左ツリー右クリック「Open in new tab」**: md / .out を webview 内の新しいタブで開きます。

### 改善
- standalone md のデフォルト画像/添付保存先を、md 直下から `images/` `files/` サブフォルダに変更（Notes・outliner と統一）。
- サイドパネル幅の不具合を修正: ノートを開き直すと幅がデフォルトに戻る問題、ウィンドウ幅を変えるとサイドパネルがエディタ領域をはみ出す問題。
- サイドパネル md の「新しいタブで開く」ボタンを、閉じるボタンと同様に固定表示（幅が狭くても隠れない）。

### 削除された設定
- `fractal.outlinerPageTitle`（ページタイトル入力は常に表示になりました）
- `fractal.imageDefaultDir` / `fractal.fileDefaultDir` / `fractal.forceRelativeImagePath` / `fractal.forceRelativeFilePath`（保存先の指定方法が上記に変わりました）
- ※ 既に settings.json にこれらのキーが残っていても無視されるだけで、動作に影響はありません。
