# Release v0.207.56 — Outliner subtree → llms.txt 風コピー

## ハイライト

Outliner ノードの右クリックメニューに **配下 subtree を llms.txt 風 Markdown でコピー**する機能を追加。配下を再帰的に辿り、階層構造を見出し化、添付 (MD page / file) を bullet リンクで出力する。

3 つの mode を用意：

| メニュー項目 | 出力対象 | 用途 |
|---|---|---|
| 配下の **MD 構成**をコピー | pageId 添付ノードのみ | Wiki / docs サイトの page index |
| 配下の **ファイル構成**をコピー | filePath 添付ノードのみ | PDF / その他添付ファイルの参照リスト |
| 配下の **MD + ファイル構成**をコピー | 両方統合 (両方持つノードは 2 本 bullet) | 両方のパスを一括取得 |

## 出力フォーマット

右クリックしたノードを root として H1、その子孫を H2〜H6 で階層化。添付ありの leaf は bullet 化。中間ノード (子あり・添付なし) は見出しとして残し階層を保持する。

例:

```markdown
# Root

## SectionA

- [LeafA1](/abs/path/to/A1.md)
- [LeafA2](/abs/path/to/A2.md)

## SectionB

### Deeper

- [Leaf](/abs/path/to/leaf.md)
```

## ルール

- **深さ 7 以降は H6 で clamp** (Markdown 見出しの上限に合わせる)
- **添付なし & 子なし leaf はスキップ** (出力をクリーンに保つ)
- **disk に実体がないパスは bullet 出さない** (`fs.existsSync` false なら除外)
- **絶対パスで出力** (どこに貼っても使える)
- **MD mode と File mode は厳密に分離**: file mode で MD page が混入することはない (unit test で resolver が呼ばれないことを assert)
- **テキストクリーニング**: `#tag` `@mention` ・ Markdown 強調 (`**bold**` 等) は除去、空 text は `Untitled`

## 動作場所

- ✅ Standalone outliner (`.out` を直接開いた場合)
- ✅ Notes mode の outliner panel (Notes editor 経由で開いた場合)

## i18n

en / ja / es / fr / ko / zh-CN / zh-TW の 7 言語にメニューラベルを追加。

## テスト

`test/unit/llms-txt-builder.spec.ts` に 14 件の unit test を追加 (全 pass):

- 各 mode で正しい出力
- File mode で MD page resolver が**呼ばれないこと**を assert
- Both mode で同一ノードが 2 本 bullet 化
- 中間ノード見出し化、leaf スキップ、disk 不在 skip、H6 clamp、テキストクリーニング、空 text fallback
