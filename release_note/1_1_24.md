# Release 1.1.24

## ハイライト
- **note 間コピペでファイル実体が付いてくるようになった（4 経路完備）**
- **sidepanel ヘッダーの「…」オーバーフローメニュー**

## 詳細な変更内容

### 新機能
- **cross-note paste の asset 複製 4 経路完備**: md 内の画像・📎 添付・subpage リンクを範囲選択でコピー（cmd+c / cmd+x）して別 note に貼ると、リンク先の実体ファイルが貼り付け先 note に複製される
  - **md → md（メインペイン）**: 従来は sidepanel md 限定だった複製機構（三重ゲート: copy 側 / paste 側 / host 側がすべて sidepanel 専用）をメイン md にも対称配線。subpage md はその中の画像も含め再帰的に複製
  - **md → outliner**: 行全体が画像 / 📎 / subpage リンクの行はそれぞれ画像ノード・ファイル添付ノード・page ノードになり、クリックで開ける（従来は生テキストが貼られてリンク切れ）。テキスト混在行はリンクを貼り付け先で解決できる相対パスに書き換え。通常の外部テキスト paste は従来どおり
  - cut (cmd+x) は既存 cross-note セマンティクスに統一: 同一 note 内 = 移動（複製しない）/ 別 note = 複製 + 元ファイルは orphan として cleanup が回収
  - outliner → md / outliner → outliner の既存経路は無変更
- **sidepanel ヘッダーの overflow「…」メニュー**: パネルが狭いとき、入りきらないボタンだけが右端から順に「…」メニューへ格納される（VS Code ツールバー方式）。広げると順次直接表示に戻る。従来の「4px の横スクロールバーで実質押せない」問題を解消。翻訳ビューとも共存

### 修正
- **スペース入りファイル名（`My Document.docx` 等）が複製から silent に脱落するバグ**: asset 抽出の正規表現がスペースで打ち切られていた。正典 markdown リンクパーサ（括弧バランス走査）ベースに置換し、md → md / md → outliner の両経路で修正

## 設計メモ
- transport は既存 `text/x-any-md-context` 方式の対称拡張（ADRL-0046。Store 移行は将来 supersede 余地）
- overflow メニューは「ボタン DOM 不動 + CSS 非表示 + プロキシ委譲」（ADRL-0047。既存の 2 実装並存ボタン配線を断線させない）
