# Release 1.2.1

## ハイライト
- **移行ゲート・移行完了通知・翻訳系メッセージの多言語化** — host 側に日本語ハードコードで
  残っていたメッセージを 7 locale（en / ja / es / fr / ko / zh-CN / zh-TW）対応にした

## 詳細な変更内容

### 修正
- **移行ゲート画面**（旧レイアウト note を開いたときの画面）: タイトル・説明・サマリラベル
  （ページ/画像/ファイル）・「移行する」「再試行」ボタン・進行中/失敗表示のすべてが
  VS Code の表示言語（または `fractal.language`）に追従。HTML の `lang` 属性も locale 追従
- **移行完了 toast**: バックアップ場所の案内・復旧手順・参照先不明の警告を i18n 化
- **翻訳（Amazon Translate）系**: 翻訳結果の保存成功/失敗、用語集（terminology）の
  更新成功/失敗・設定不足エラー・アップロード進行表示を i18n 化
- 新設 24 キーを Messages interface + 7 locale 全ファイルに登録。`src/` への日本語
  ハードコード再混入を防ぐ恒久ガードテスト（TC-HMI-04）を追加
- 既存テストの改善: 移行ゲートの「再試行」ラベル検証が JS コメントにヒットする偽 green
  だったのを実代入行の検証に強化
