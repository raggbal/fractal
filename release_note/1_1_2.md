# Release 1.1.2

## ハイライト

**Mindmap の Group に右クリックメニューが付きました** — 名前の設定・変更・削除、Group の削除。

## 詳細

### 新機能
- Group 枠を右クリック → **Rename Group…**（入力ダイアログで命名。枠左上に表示・保存・undo 可。空文字で名前だけ削除）/ **Delete Group**（枠だけ削除、ノードは残る）

### 修正
- Group 枠を右クリックすると「Create Group」が出ていたバグ（Group 上の右クリックが空白扱いに落ちていた）
