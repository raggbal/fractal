# Release 1.1.16

## ハイライト
- **AWS CLI が不要に** — S3 sync と翻訳が AWS SDK 内蔵になり、設定にキーを入れるだけで動作
- **翻訳ボタンをツールバーに常設** — note / standalone markdown、simple toolbar でも PDF ボタンの左に表示
- **sidepanel 翻訳の誤爆修正** — 翻訳結果は要求した側（sidepanel / メイン）にだけ届く

## 詳細な変更内容

### 変更: S3 sync / 翻訳の AWS SDK 化（CLI 依存の排除）
- aws CLI の子プロセス呼び出しを AWS SDK for JavaScript v3 に完全移植。**CLI のインストール・PATH 設定・バージョン管理が不要**になり、設定（`fractal.s3AccessKeyId` 等）に認証キーを入れるだけで S3 sync と Amazon Translate が動く
- 同期の意味論は従来と同一: per-file mtime の newer-wins・`--delete` 不使用（データ損失なし）・失敗時は即中断（fail-fast）
- 削除系 API は「全消し再アップロード」の明示操作 1 経路のみ（同期経路には構造的に存在しない）
- **既知制約**: HTTP(S) プロキシ経由の接続は現在非対応（README に明記。ニーズがあれば opt-in 設定を検討）
- 内部: 拡張本体を esbuild で単一バンドル化（SDK 同梱・約 1MB）。テストが 0 件実行になる collection 失敗を検出する CI gate を追加

### 変更: 翻訳ボタンの表示面拡大
- `fractal.showTranslateButtons` が ON なら、**note markdown / standalone markdown の両方**で、**toolbar が simple モードでも**翻訳ボタンが見える（配置 = PDF ボタンの左）
- 従来 full モードのツールバー内にあった翻訳ボタン群は非表示にして 1 箇所に一本化（二重表示回避）
- 押すと従来どおりの翻訳結果画面（← Back で復元）

### 修正: sidepanel 翻訳のスコープ
- note md + sidepanel md を開いて **sidepanel で翻訳するとメインの note md まで翻訳画面になっていたバグ**を修正。応答に要求元の識別を持たせ、要求した側にのみ適用
- 逆方向（メインで翻訳 → sidepanel が翻訳画面に汚染される潜在バグ）も同時に修正
- 翻訳結果画面（read-only）から app link / Open in new tab ボタンを除去（閉じる・戻るで復元）
- sidepanel の app link ボタンの角丸枠線を除去し、ヘッダボタンの間隔ズレ（margin と gap の二重加算）を解消

## 移行ガイド
- **aws CLI はアンインストールしても構いません**（Fractal は使わなくなりました）。設定キー（s3AccessKeyId / s3SecretAccessKey / s3Region / transAccessKeyId 等）はそのまま使われます
- プロキシ必須の環境で S3 sync / 翻訳を使っていた場合は v1.1.15 以前に留まるか、issue でお知らせください
