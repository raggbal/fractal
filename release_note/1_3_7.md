# Release 1.3.7

## ハイライト

1. **PowerPoint の表示忠実度を大幅修正** — 実業務 deck で発覚した 6 つの描画バグ（背景色・段落間隔 100 倍・SVG-only 画像消失・EMF 壊れ表示・autofit 未適用・リスト番号/バレット）を修正。実 deck のスクリーンショット比較で PowerPoint の表示とほぼ一致
2. **ベクタ EMF 画像の実描画** — 依存ゼロの自前 EMF→SVG 変換器を新設（ADRL-0097）。PowerPoint がロゴ等で使う EMF-only 画像が Word/PowerPoint viewer の両方で実描画される（変換不能な EMF/WMF は従来どおり整った縮退枠 — 「不確実なら描かない」契約）
3. **Kiro 等の Chromium<140 フォークで PDF が開けない問題を修正** — pdf.js を legacy ビルドに切替（版 pin 5.5.207 は不変・CVE 範囲外維持）

## 詳細

### PowerPoint viewer（修正）
- 背景 `bgRef` → テーマ背景スタイルの placeholder 色継承（clrMap 反転テーマで背景が白くなる）
- 段落前後間隔 `spcPct` の単位（1/1000%）— 100 倍の margin で本文が画面外に飛んでいた
- `svgBlip` のみ（raster fallback 無し）の SVG 画像のフォールバック解決
- EMF/WMF/TIFF の placeholder 縮退の復元（壊れ `<img>` 化の退行）
- normAutofit: 保存値（fontScale/lnSpcReduction）の適用 + **表示時の実計算 shrink-to-fit**
- リストマーカー: ol 連番（空段落は番号非消費）・マーカーのサイズ/色継承・ぶら下げインデント

### EMF→SVG 変換器（新規・viewer-common/emf.mjs）
- 対応レコードのホワイトリスト方式（path fill/stroke 系）。subset 外・parse 失敗・上限超過は null → 既存 placeholder に縮退
- 非信頼入力向けの 4 上限（入力 5MB / レコード 2 万 / 点数 2 万 / 出力 SVG 2MB）+ 全 offset 境界チェック。出力は数値 path と hex 色のみ（injection 面ゼロ）
- pptx / docx 両 viewer に配線

### PDF viewer（修正）
- バンドル生成元を pdf.js legacy ビルドへ（modern は Chrome 140 API を polyfill なしで使用 — Chromium<140 の webview で全滅）。切り戻りは TC-FV-79 が恒久検出
