# Release v0.207.22 — Minimal Pastel Chrome Foundation

## ハイライト

- 🎨 **chrome (panel / toolbar / list / settings / popup) を minimal pastel デザインに刷新** — VSCode テーマ追従を捨てて独自パレット固定
- 🌗 **7 themes 撤廃 → 3 mode (`light` / `dark` / `auto`)** — シンプルかつ OS 連動
- ⚙️ **VSCode 設定 3 件撤廃** (`outlinerImageDefaultDir` / `outlinerFileDir` / `outlinerPageDir`) — convention で自動解決

---

## 詳細な変更内容

### 🎨 minimal pastel chrome foundation

#### 新 design tokens 体系

`src/webview/` に 3 つの新 CSS:

- **`tokens.css`** (247 行): 115 個の `--fr-*` 変数を `light` / `dark` / `auto` の 3 mode で完備
  - 色: brand (primary / accent) + surface (bg-app / bg-panel / bg-elevated) + text (primary / secondary / tertiary / muted) + status (success / warning / danger / info)
  - 余白: 2 / 4 / 6 / 8 / 10 / 12 / 16 / 20 px の dense scale
  - 角丸: 4 / 6 / 8 / 10 / 9999 px
  - 影: shadow-1 / -2 / -3 + shadow-focus
  - typography: 11 / 12 / 13 / 15 / 18 / 22 px scale + font-family / weights
- **`fr-base.css`** (76 行): reset / scrollbar (8px、light/dark) / `:focus-visible` (button/input/textarea/select のみ) / `::selection` / theme transition
- **`fr-components.css`** (238 行): `.fr-button` (4 variants × 3 sizes) / `.fr-input` / `.fr-list-item` / `.fr-context-menu` / `.fr-popup` / `.fr-badge`

#### CSS Cascade Layers

```css
@layer fr-legacy, fr-tokens, fr-base, fr-components, fr-chrome;
```

`fr-legacy` (VSCode `var(--vscode-*)` fallback) より `fr-tokens` (minimal pastel) が後で勝つ cascade。

#### Layout 不変原則

PoC 段階で 47 selector × bbox 静的解析 = 0 px drift を検証済。padding / margin / width / height / gap / line-height / font-size は完全不変、配色 / 角丸 (4 → 6 px) / focus / hover のみ刷新。

### 🌗 3 mode theme system

#### 撤廃された 7 themes

`github` / `sepia` / `night` / `dark` / `minimal` / `things` / `perplexity` は全廃。これに伴い旧 typography 微調整 (perplexity / things の H1/H2/blockquote/table 等 60+ selectors) も削除。

#### 新 3 mode

| theme | 説明 |
|-------|------|
| `light` | pastel cream bg (`#FAFAF7`) + 黒テキスト |
| `dark` | deep navy bg (`#1E1F28`) + 明るめテキスト |
| `auto` (default) | OS の `prefers-color-scheme` に追従 |

#### 自動 migration

旧 enum 値が `fractal.theme` に残っているユーザーは、初回起動時に 1 回限定の warning notification (`themeMigrationNotice` 7 言語) で通知 + 自動的に新値に書き換え + `globalState.fractal.themeMigrationDone` で重複防止:

| 旧値 | 移行先 |
|------|--------|
| `dark`, `night` | `dark` |
| `things`, `github`, `sepia`, `minimal`, `perplexity` | `light` |
| その他 (typo 等) | `auto` (safe fallback) |

### ⚙️ VSCode 設定 3 件撤廃

- `fractal.outlinerImageDefaultDir`
- `fractal.outlinerFileDir`
- `fractal.outlinerPageDir`

#### 動機

notes mode 経由 + standalone 経由のどちらも `<basename>/` convention で path 解決可能。設定経由 override は誰も使っていない、設定 UI を簡素化。

#### 解決順 (3 段階の fallback)

1. `.out` JSON の `data.imageDir / pageDir / fileDir` (per-file override)
2. convention default: `./<basename>/images` / `./<basename>/` / `./<basename>/files`
3. legacy fallback: 旧構造 `./images` / `./pages` / `./files` が物理的に存在する場合のみ

### 🆕 機能追加

#### Multiselect popup keyboard navigation

outliner table mode の multiselect cell popup で:

- **↓**: 次の list item を highlight (`.is-highlighted` class)
- **↑**: 前の item、`-1` で input に戻る
- **Enter**: highlight 中の item を選択 (mousedown dispatch で既存 toggle/create 再利用) + popup close + cell に focus 戻す
- **ESC**: popup close + cell focus 戻す

#### Multiselect cell の simulated text caret

text editing / native picker が無い multiselect cell に focus 判別 indicator として `::before` で 1 px × 1.2em の blink caret を表示 (`outliner-caret-blink` keyframe、1s で blink)。

#### Outliner table mode の日付/日時列対応

- **Cmd+矢印キー navigation**: text / multiselect / outline 列と同等の挙動。input 化前/後どちらでも動作
- **shift+↑↓ 範囲選択**: 日付/日時列も `is-selected` (黄色) になる (旧 `toggleRowCellsClass` は text + multiselect のみ → date 追加)
- **行高さに合わせた縦伸長**: `align-self: stretch` rule に `.outliner-cell-date` 追加 → hover bg 下部欠け解消
- **上合わせ**: `align-items: center` → `flex-start`
- **focus 時 minimal**: native browser focus ring を transparent / none に

### 🎨 Settings panel chrome 刷新

`src/shared/notes-body-html.js` の Tools tab S3 領域:

- 配色 var を `var(--vscode-*)` → `var(--fr-color-*)` に置換 (約 23 箇所)
- focus styles に `box-shadow: var(--fr-shadow-focus)` (4 selector)
- selection bar: `.file-panel-item.active::before` で 2 px primary bar (タブ underline と統一)
- border-radius: 4px → `var(--fr-radius-sm, 6px)` (5 箇所、bbox 不変)
- danger / success / error 状態色を tokens 化
- **layout 値 (padding / margin / width / height / gap / line-height / font-size / border 幅) は完全不変**

### 🎨 Outliner / MD editor body の bg 統一

`bg-app` と `bg-panel` を同一値に統一:
- light: `#FAFAF7` (off-white)
- dark: `#1E1F28` (deep navy)

sidebar / content / toolbar 全て同色になり、コンテンツ領域の灰色感を解消。`bg-elevated` (`#FFFFFF` / `#2A2B36`) は popup / hover の elevation 用に維持。

### 🔇 focus 時の minimal 化

text editing 中に白背景 + 水色枠で強調されていた挙動を撤廃:

- `.outliner-text:focus` / `.outliner-cell-text:focus` / `.outliner-cell-multiselect:focus` / `.outliner-cell-date-input:focus` / `.outliner-subtext.is-editing` で background / outline / box-shadow 全て transparent / none
- `fr-base.css` の general `:focus-visible` 2px outline rule を撤去し、button / input / textarea / select のみに limit (contenteditable には focus ring を当てない)

### 🔇 outliner editor の hover 反転撤廃

keyboard navigation と hover の協調が複雑だったため、outliner editor 全体で hover 反転を撤廃:

- `.outliner-node:hover` 削除
- `.outliner-tree[...] > .is-row-hover` rule 削除
- 関連 JS (row-hover 検出 / suppress-hover) 全削除

**保持する hover** (UX 上必要なため):
- notes file panel `.file-panel-item:hover` (selection-bg / water-blue)
- popup `.file-panel-context-item:hover` (右クリックメニューの標準 UX)

## 移行ガイド

### 7 themes ユーザー

VSCode 設定 `fractal.theme` を旧値 (`github` / `sepia` / `night` / `dark` / `minimal` / `things` / `perplexity` のいずれか) に設定している場合、初回起動時に通知 (例: 「テーマ設定 `things` → `light` に自動移行しました。」) が出て自動的に新値に置換されます。settings UI からは新 3 値のみ選択可能。

### 設定 3 件を customize していたユーザー

`fractal.outlinerImageDefaultDir` / `fractal.outlinerFileDir` / `fractal.outlinerPageDir` をカスタム path に設定していた場合、その値は無視されて convention default (`./<basename>/...`) で動作します。

per-file レベルでの override が必要な場合は `.out` ファイルの JSON に直接 `imageDir` / `fileDir` / `pageDir` フィールドを追加することで対応可能 (priority 1)。

### 旧構造 (`./images` / `./pages` / `./files` を root に置いてた人)

新規作成は `./<basename>/images` 等の convention に従いますが、既存の旧構造ファイルは legacy fallback で継続動作 (旧 directory が物理的に存在する場合に自動検出)。手動で `<basename>/images/` 等に移動するも可。
