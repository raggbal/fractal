# Release 1.3.3

## ハイライト

- **md の移動が「まるごと」動くように** — note 間・linked folder ⇄ ツリーの md D&D 移動/複製で、画像・📎 添付・subpage（再帰）が自動で随伴し、note フラット ⇄ フォルダ隣接のレイアウト変換も自動化
- **vscode server での Explorer D&D 復活** — `vscode-remote://` URI の drop を受理
- **フォルダビューの使い勝手 3 点** — 隠しファイル表示トグル / ファイルアイコンのシングルクリック open / ディスク変化の自動リロード

## 詳細な変更内容

### 新機能
- 随伴転送（FR-ACC-01..03）: 面間 md 転送で本文参照アセットの再帰複製 + リンク書換え + レイアウト変換
- フォルダビュー Duplicate（FR-ACC-04）: md（随伴込み）/ file の複製
- フォルダビュー 👁 隠しファイルトグル（FR-FLV-31・folder link ごとに永続化・検索追従）
- ファイル行アイコンのシングルクリック open（FR-FLV-32）
- フォルダビュー自動リロード（FR-FLV-33・fs.watch recursive・表示中のみ）

### 改善・仕様変更
- **source containment（NFR-ACC-02b）**: 移動/複製時の資産読取は移動元のテリトリー内に限定（絶対パス・境界外 `../` は非随伴・リンク原文温存）— 細工 md による任意ローカルファイルの持ち出し（→ S3 同期流出）を遮断。クリップボード paste は従来どおり
- **trash 不能環境の移動フォールバック（FR-FLV-34）**: vscode server 等では複製確認済みの元ファイルを直接削除（移動が複製にならない）。Delete/Rename は従来どおり trash 限定

### 修正
- vscode server の Explorer D&D（FR-RMT-01）
- cross-note D&D の判定穴（A→B 方向で跨ぎ相対リンクが挿入されるケース）
- md サブページリンク → ツリー移動時の元ファイル側リンク除去（fs 反映）ほか移動系 source 除去の統一
- 隠しトグル時の全面リロード（展開中サブフォルダ含む）
