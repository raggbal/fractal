# Release 1.1.0

## ハイライト

**Mindmap でも Task 機能が使えるようになりました。** これまで Outliner view 限定だった
Task Mode（チェックボックス / 完了フィルタ / アーカイブ）を、Mindmap view でもフル操作できます。

## 詳細な変更内容

### 新機能: Mindmap Task Mode

- **チェックボックス操作**: Mindmap 上のノードのチェックボックスをクリックで完了/未完了を切替。
  Outliner で付けたチェックは Mindmap にそのまま現れ、逆も同じ（データは単一の `node.checked` を共有）。
- **キーボード**: `Cmd+Shift+X` でチェックボックス追加/完了トグル、`Cmd+Shift+Option+X` で削除
  （Outliner と同一バインド）。
- **右クリックメニュー**: ノード右クリックに Add Checkbox / Remove Checkbox（表示言語に追従）。
- **完了フィルタ**: フィルタが「未完了のみ」のとき、完了ノードは**子孫と接続線ごと**マップから消えます。
  レイアウトも詰め直され、minimap / fit-to-screen / export も整合します。全ノードが完了で消えた場合は
  空状態表示になり、フィルタを戻せば復帰します。
- **ヘッダーボタン**: Task Mode / Task Filter / Archive の 3 ボタンが Mindmap 表示中もグレーアウト
  されなくなりました（menu / ナビ履歴 / 検索モード切替は従来どおり Mindmap では無効）。
- **Archive**: Notes モードでは完了タスクのアーカイブも Mindmap から実行できます（Outliner と同一結果）。

### 修正

- Mindmap ヘッダーの task 系ボタンの click 配線を冪等化（再初期化環境での二重発火を防止）。
- 過去の仕様変更（空ノードの `Cmd+Enter` で md 作成）に追随していなかった古いテスト期待値を更新。

## 内部変更（開発者向け）

- `MindmapLayout.compute` に第 5 引数 `hideNode: (nodeId) => bool`（省略可・後方互換）を追加。
  レイアウトから任意ノードを subtree ごと除外する純述語で、Task Filter はこれを通じて実現
  （layout は task の意味論を知らない — ADRL-0018）。
- ヘッダーボタン有効化は TASK-77 決定の部分 supersede（ADRL-0017）。
