# Release 0.209.48

## ハイライト
- **タイトル ↔ H1 双方向同期**: ファイルツリー名/ノードのテキストと、Markdown の先頭 H1 が編集確定時に自動で揃うようになりました。

## 詳細な変更内容
### 新機能
- note md: ファイルツリーで rename → md 先頭 H1 に反映 / 先頭 H1 を編集 → ツリー名に反映（双方向）。
- outliner: node の text 編集 → 添付 page md の H1 に反映 / sidepanel で開いた page md の H1 編集 → 呼び出し元 node の text に反映（双方向）。
  - sidepanel md → node の反映は「outliner node から開いた md」のときだけ（リンク/履歴/検索から開いた md は対象外）。

### 修正
- `C#` / `F#` のような末尾 `#` を含むタイトルが切り詰められるデータ化けを修正（CommonMark ATX 準拠）。CRLF 保持。
- 未編集の node を Cmd+Enter しただけで md H1 が古い text で上書きされる問題を修正。
- outliner の title 変更が note ファイルツリーに即反映されない問題を修正。
