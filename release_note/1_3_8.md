# Release 1.3.8

## ハイライト

- **重大バグ修正: 入力中に backspace で消した文字が復活する（編集が巻き戻る）問題を根治**

## 詳細な変更内容

### 修正

**Backspace の削除が「途中から効かなくなる」バグ（markdown editor / outliner / notes / sidepanel md の全編集面）**

- 症状: リスト等で連続入力していると、backspace で消したはずの文字が 1〜2 秒後に復活する（体感は「backspace が効かない」）。入力した文字が消えることもある
- 根因: 外部編集ライブ反映（v1.1.23 の live-reload）の照合処理が、**自分自身の auto-save が生んだ遅延ファイルイベント**を「外部編集」と誤認し、document と画面を 1 世代前のディスク内容へ巻き戻していた（恒久 lost-update）。編集中は document がディスクより常に先行するため、従来の「disk vs document 差分チェック」では自己保存を吸収できなかった
- 修正: **自己書き込み台帳（self-write ledger）** — 自分が書いた内容の指紋（正規化ハッシュ・per-file 直近 16 世代）を保持し、照合時にディスク内容が台帳にあれば no-op。同型 4 箇所（notes メインペイン / sidepanel / standalone md / outliner .out）すべてに適用
- 保証: 本物の外部編集（Claude Code・他エディタ、in-place / atomic rename どちらの保存方式も）は従来どおりライブ反映される（回帰テストで pin）。判定は内容照合のみで、イベントを捨てるタイミングヒューリスティックは導入していない（エッジトリガ消失を再導入しない）

### 変更なし（明示）

- 打鍵中に外部ツールがファイルを書き換えた場合の意味論は従来どおり **last-writer-wins**（エディタ側が勝つ。3-way マージはスコープ外）
