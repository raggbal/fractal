# Release 1.3.1

## ハイライト

- **ローカルフォルダリンク（tree 第 4 管理対象）**: 手元の任意のフォルダを note のファイルツリーに 🔗 リンクとして登録できるようになりました。クリックするとメインペインに**フォルダビュー**（Outliner 風のファイルツリー）が開き、note の外にあるファイル群を note と同じ場所で眺め、開き、整理できます
- **面をまたぐ D&D はすべて「移動」**: フォルダビュー ⇄ Note ツリー ⇄ サイドパネル md の間でファイルを D&D すると、実体が移動します（複製が成功してから元を OS のゴミ箱へ — 恒久削除する経路はありません）。ファイルの置き場が一本化され、増殖しません
- **md アウトライン（TOC）の白背景バグ修正**: 1.3.0 の file viewer 同梱 CSS が md の目次サイドバーの配色を乗っ取っていた回帰を修正しました

## 詳細な変更内容

### ローカルフォルダリンク / フォルダビュー

- ツリーヘッダの「+linkfd」からフォルダを選択して登録。行アイコンは 🔗 チェーンリンクで、通常のツリーフォルダと一目で区別できます
- フォルダビューは lazy 読み込み（直下 1 階層ずつ）で、巨大フォルダでも初回表示が待たされません。名前の絞り込み Search・Refresh ボタン付き
- ファイル操作: New Markdown（入力した名前が H1 として本文に入る）/ New Folder / **Enter でその場 rename**（IME 対応・ポップアップ廃止）/ Delete（**常に OS のゴミ箱経由** — 復元できます）
- md はサイドパネルで、.pdf / .html は内蔵ビューアで、その他は OS の既定アプリで開きます（cmd+enter / ダブルクリック）
- フォルダの開閉状態はリンク先直下の隠しファイル `.fractal-folderview.json` に保存され、再起動後も復元されます（相対パスのみ・マシン間で共有可能）
- リンク先が消えても item は残り「リンク切れ」表示に。click / Re-link で付け替えられます
- サイドパネルで開いた md がリンクフォルダ配下のものだと、ヘッダに「🔗 リンク名」バッジが出ます。esc でサイドパネルを閉じるとフォルダビューにフォーカスが戻り、そのまま ↑↓ で次のファイルへ移動できます

### 安全性（重要な設計）

- リンク先フォルダは**参照**であり、Fractal は実体管理をしません — Clean Notes の削除候補・S3 同期の転送対象には決してなりません
- フォルダビュー起点の全ファイル操作はリンク先フォルダ配下に**二段検査（パス正規化 + realpath 実体検査）でクランプ**され、外側への書き込み・削除・読み出しは構造的に発生しません
- 削除・面間移動の「元の削除」はすべて OS のゴミ箱経由。ゴミ箱への移動が失敗した場合（クラウドドライブ等）はエラー通知して元を残します（黙って二重化しない）

### 修正

- **note md のアウトライン（TOC サイドバー）が白くなる**: 1.3.0 の pdf.js viewer 同梱 CSS の汎用 `.sidebar` セレクタが原因の回帰。特異度の高い打ち消しルール + 回帰テストで修正
- フォルダビュー表示後に Note ツリーのクリックが効かなくなることがある問題
- サイドパネル表示中にフォルダビューで cmd+enter による次ファイル切替ができない問題（サイドパネルの自動フォーカス奪取）
- フォルダビューの見た目を Outliner に完全統一（背景・選択行・開閉三角・ヘッダ UI・行アイコン。hover で行の色は変わりません）

## 既知の制約

- **旧バージョンとの前方互換**: フォルダリンク入りの note を旧バージョンの Fractal で開くと、リンク登録がツリーから消え、S3 同期で他マシンへ伝播することがあります。失われるのはリンク登録のみで**実フォルダは無傷**です（再登録で復旧）
- リンク先フォルダの外部変更（Finder 等）は Refresh ボタン / 表示時などの契機で反映されます（常時監視はしません）
