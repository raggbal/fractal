# Release 0.209.6

## ハイライト
- **Mindmap Mode の実機フィードバック反映（iteration 24–28）**。v0.209.2 リリース後、実機での手動テストで見つかった操作性・視認性の挙動バグをまとめて修正。
- すべて **既存 FR-021 の挙動修正**であり、仕様変更・新機能追加はなし（patch リリース）。

## 詳細な変更内容

### 改善（iteration 24）
- **ズーム時の中心化**: ツールバーの +/− ボタン・トラックパッド（Ctrl/Cmd+wheel）のどちらでも、選択中（active）ノードを画面中心に寄せながらズーム/ズームアウトする。
- **複数選択の視認性**: shift+click の複数選択が、はっきりした枠（背景＋選択リング）で表示される。以前は選択が解除されたように見えていた。
- **Group 作成で画面不動（scale≠1）**: ズームした状態で Create Group しても、固定ノードの画面位置が保たれる（viewBox シフトを補償）。

### 改善（iteration 25）
- **active 太枠の一貫性**: 矢印/Enter/Tab で active が別ノードへ移ると、クリックで付いた太枠は消え、移動先のみが太枠になる。複数選択（shift 操作）はそのまま維持。

### 改善（iteration 26）
- **Delete 後の active 移動**: ノード削除後、active が「上の兄 → 下の弟 → 親」の優先順で残存ノードへ移り、続けて操作できる。

### 改善（iteration 27）
- **Delete で画面（pan/zoom）を動かさない**: 削除時に viewport の translate/scale を保持する（削除に伴うツリー再レイアウトは自然な挙動として残る）。
- **ひらがなで即編集（IME 対応）**: 確定ノード上でひらがなを打ち始めると、英数にリセットされずそのまま編集モードに入り日本語が入力される。
- **トラックパッドのズーム高速化**: Ctrl/Cmd+wheel の 1 操作あたりの変化量を増やし、体感を速くした。

### 修正（iteration 28）
- **矢印移動で編集モードに見えない**: 選択中（active）ノードはキャレットを表示せず、編集を開始したときだけキャレットを出す。iteration 27 で IME 対応のため active ノードを編集可能化した副作用（矢印移動先が編集モードに見える）を是正。
