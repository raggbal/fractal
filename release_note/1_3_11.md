# Release 1.3.11

## ハイライト

- **HTML viewer の zoom out で右下に余白が出る問題を修正**（100vh レイアウトのアプリ型ページ — ブラウザズーム同等の reflow へ方式変更）
- **⟲ zoom リセットボタンを追加**（[−][+] を持つ全 viewer）

## 詳細な変更内容

### 修正

**HTML zoom 方式 v2（FR-VZP-02b / ADRL-0101）**

- 症状: ダッシュボード等の `100vh`/`height:100%` ベースの HTML を縮小すると、ページを包む箱ごと縮んで右下に余白が出る（v1.3.10 で導入した iframe 内 CSS zoom の本質的限界 — CSS zoom はレイアウトビューポートを広げないため vh 基準の箱が縮む）
- 修正: 親側で iframe 要素自体を `width/height=(100/z)% + transform: scale(z)` にする方式へ変更。iframe 内部のビューポートが実際に CSS px で拡縮されるため、**任意の倍率でページがペイン全体を埋めたまま reflow** する（ブラウザの Cmd/Ctrl± と同じ見え方。拡大側も折り返しが増える自然な reflow）
- 倍率状態は親側で一元管理（スクリプト許可トグルの再描画をまたいで維持）。iframe 内のピンチ捕捉と VS Code 全体ズーム抑止は従来どおり

### 新機能

**⟲ zoom リセット（FR-VZP-06）**

- [−][+] を持つ 6 kind（pdf/pptx/docx/xlsx/text/html）に ⟲ を追加 — 開いた直後の倍率へワンクリックで復帰
- pdf は page-width フィットへ復帰し、**幅追従の自動再フィット（v1.3.9）も再開**
- image は既存 [フィット] が同機能のため対象外（重複ボタンなし）
