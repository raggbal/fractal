# Release 1.1.25

## ハイライト

1. **Note ファイルツリーが「ファイル」を扱えるように** — md / アウトライナーに加え、PDF・Excel・zip などの任意ファイルをツリーで管理。外部から D&D で取り込み、クリックで OS 既定アプリが開きます。
2. **D&D 8 経路の完備** — ツリーのファイルを outliner / markdown（メイン・サイドパネル）へ、またその逆へ、双方向に D&D できます。実体は共有 `files/` から動かさず「所有」だけが移る安全設計。
3. **D&D の使い勝手・信頼性修正 6 件** — 先頭行への drop が末尾に化けるバグ、md 内 📎 リンクが実際には drag できなかった問題などを解消。

## 詳細な変更内容

### 新機能（FR-TF 系）

- **外部 → ツリー D&D**: どんな拡張子でも受理（従来は非 md を無通知スキップ）。元ファイル名保持・同名は `-N` で一意化・1 ファイル 50MB 上限（超過は明示エラー）。
- **クリックで外部アプリ起動**: ツリーのファイル項目は `vscode.env.openExternal` で OS 既定アプリへ。
- **ツリー内 D&D**: ファイル → .out 項目（先頭に 📎 添付 node）/ ファイル → md 項目（末尾に `[📎 名前](files/…)` リンク追記）。
- **エディタとの双方向 D&D**:
  - ツリー → 開いている Outliner: drop 位置（before/after/child）どおりに 📎 node 挿入。補助線も表示。
  - Outliner の 📎 アイコン → ツリー: ファイル項目として登録（子なし node は消える・子持ちは添付だけ外れる）。
  - ツリー → 開いている Markdown（メイン / サイドパネル）: 📎 リンク挿入。
  - md の 📎 リンク → ツリー: 登録 + 元リンク除去。
- **コンテキストメニュー フルパリティ**: Open / Reveal in Finder / Rename（表示名のみ）/ Favorite / Copy Path / Set Color / Move Other Note / 新規作成 3 種 / Delete。
- **検索**: ツリーの絞り込みでファイル名にヒット（`[file]` バッジ）。
- **安全性**: Clean Notes はツリー登録ファイルを保護（誤削除しない）。起動時に実体欠損項目を自己修復。ファイル名の markdown 破壊文字はサニタイズ。パス解決は全経路 clamp。

### 修正

- 先頭行への drop（before）が末尾挿入に化けるバグ（file / md / import の 3 経路すべて）
- md 内 📎 リンクが実際にはマウスで drag 開始できなかった問題（contenteditable の機序を特定し解消）
- ツリー谷間・余白への drop が不発になる問題
- tree → outliner で md/file を drop する際、outliner 全面ハイライトだけで位置調整できなかった問題

### 既知の制約（スコープ外・次フェーズ候補）

- fractal:// のファイルリンク / export bundle への同梱 / fractal-search skill のファイル対応 / ファイル内容の検索 / 50MB 超の streamed 取込
- 旧バージョンの拡張で file 項目入りの note を開くと、ツリー台帳から項目が消えることがあります（**実体 `files/` は失われません** — 再 D&D で再登録可能。ADRL-0048 記録の既知制約）
