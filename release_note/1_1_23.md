# Release 1.1.23

## ハイライト
- **Claude Code / kiro 等の AI CLI で md を編集したとき、エディタにリアルタイム反映されない問題を修正**（standalone / sidepanel / notes の全 3 面）

## 詳細な変更内容

### 修正
- **standalone md（通常タブ）**: 検知がファイル変更イベント 1 本足だったため、Claude Code の保存方式（atomic rename = 一時ファイル書き → 置き換え）を取りこぼしていました。sidepanel / notes と同じハイブリッド監視（変更 + 作成イベント + 1 秒ポーリング）に統一
- **sidepanel / notes md**: fractal 自身の自動保存の最中に届いた外部変更イベントを捨てていたため、タイミングが重なると永久に反映されず、次の自動保存が AI の編集を上書きして消すこともありました。イベントを捨てずに保留し、保存完了直後にディスクと照合して反映するように変更（保留照合方式）
- **フォーカスを外したとき**（別タブへ移動など）に、同期済みなのに外部更新を破棄していた問題を修正。未保存の編集がある場合の保護（編集が巻き戻らない）は従来どおり
- **sidepanel の目次（アウトライン）が外部変更に追随しない**問題を修正。notes では外部編集で H1 が変わったときツリーのタイトルも追随します

### 変わらないもの
- 打鍵中に AI が同じファイルを書いた場合の衝突は従来どおり後勝ち（last-writer-wins）。3-way マージは行いません
- 保存の仕組み・ファイル形式は不変
