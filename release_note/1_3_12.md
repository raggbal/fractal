# Release 1.3.12

## ハイライト

- **Import folder** — 外部フォルダを選ぶと、その中身が node 階層としてそのまま入る（実体は note へコピー）
- **Export folder** — 逆向き。node 階層を実フォルダ・実ファイルの木として書き出す
- **node の右クリックメニュー**から Import/Export folder が使える（対象は右クリックした node）
- **folder view 内の md 移動が資産を連れて行く**（画像・📎・subpage md）

## 詳細な変更内容

### 新機能

**Import folder（フォルダ取り込み）**

- outliner の ≡ ヘッダーメニュー、または node の右クリックメニューから `Import folder...`
- 選んだ**フォルダ自身が最上位の node** になり、その下に中身が階層で入る（サブフォルダ → node / `.md` → ページ node / その他 → 📎 添付 node）
- ファイルの実体は **note へコピー**されるので、取り込んだ後にアウトラインだけで完結する（参照ではない）
- 隠しファイル（`.` 始まり）と symlink は取り込まない。上限は 2,000 ファイル / 深さ 20 で、200 エントリを超えると確認ダイアログが出る
- 途中で失敗したファイルや、権限で開けなかったフォルダは skip して件数で通知（黙って落とさない）
- undo は 1 回で node 群がまとめて戻る（コピーした実体は残る）

**Export folder（フォルダ書き出し）**

- ≡ メニュー（focus 中の node の subtree）または node の右クリック（その node の subtree）から `Export folder...`
- **子を持つ node = フォルダ**、**子を持たない node = `<node text>.md` か添付ファイルの実体**。子ありの node が添付を持っていれば、その添付はそのフォルダの直下に出る
- node に直付けした画像は `images/` に実体を出し、生成した md からリンクする（黙って捨てない）
- 折りたたんでいる node の中身も出力される
- 名前は node text をそのまま使い、ファイルシステムで使えない文字だけ `_` に置き換える。**node text が空のときは `blank`** という名前になり、同名が重なったときだけ `blank-1`, `blank-2` と連番が付く
- 拡張子が二重になることはない（`report.pdf` という node text から `report.pdf.pdf` を作らない）
- **出力先にすでに同名のファイル/フォルダがあっても上書きしない** — 連番で退避する。md 本文の画像・📎、subpage md も同様
- 既存の **Export bundle**（1 枚のインデント md + フラット資産）とは別機能で、両方使える

**node 右クリックメニューの Import/Export**

- `Import .md files` / `Import any files` / `Import folder` / `Export folder` の 4 項目を追加（separator で既存項目と区切る）
- 対象は**右クリックした node**（≡ 側は従来どおり focus 中の node）
- 既存の `Import .md files` / `Import any files` は英語ハードコードだったので、この機会に 7 言語へ i18n 化

### 改善

**folder view 内の md 移動が資産を連れて行く**

- フォルダビュー内でフォルダ間に md をドラッグしたとき、これまでは `fs.rename` 単体だったため、md が参照する画像・📎・subpage md が元の場所に取り残されてリンクが壊れていた
- v1.3.12 からは note 間の md 移動と同じ随伴転送エンジン（コピー → 全成功を検証 → 元を trash）を通す
- **非 md（ファイル・フォルダ）の移動は従来どおり** `fs.rename` で変わらない

## 既知の制約

- Export folder の出力先ガードは Notes 面のみ（standalone `.out` 面では、note フォルダ配下への出力を止めない）
- node text が空のときの `blank` 名は Windows 実機で未検証
- Export folder が書き出す画像のファイル名には node text が混ざる（`copy-<name>-<basename>` — 既存仕様。リンクは正しく解決する）
