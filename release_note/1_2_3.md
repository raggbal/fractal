# Release 1.2.3

## ハイライト

- **リストの cut 残骸を一掃**: 階層リストをまたぐ範囲選択の cmd+X で、バレットだけの空行やアイコンだけのリンク残骸が残らなくなりました（長年のバグの根治）
- **📎 ファイルリンクが他のリンクと完全に同じ操作感に**: リンクテキストに ←→ でカーソルが入り、shift+矢印で選択、Backspace で削除できます。アイコンはこれまでどおりドラッグでツリーへ D&D 可能
- **リンクが copy/cut/paste・D&D で「リンクごと」移動**: リンクテキストを全選択して cmd+C/X → V すると、テキストだけでなくリンク（ファイル/subpage/md）ごと貼り付きます。md 内の別の場所へのドラッグ移動もできるようになりました

## 詳細な変更内容

### 修正（3 md 面共通: note md / サイドパネル / スタンドアロン）

- **リスト cut の残骸**: 選択の端点がリスト外（段落→リスト途中など）にあると掃除が丸ごとスキップされていた根因を修正。選択に交差する全 li を列挙する方式に変更
- **リンク行へのカーソル移動**: ↑↓ でリンク行がスキップされる・リスト端でカーソルが消える問題を修正
- **Enter でのアイコン複製**: リンクとテキストの間で Enter すると新行に空アンカー（アイコンだけ）が複製される問題を修正 — アンカーを原子として分割
- **📎 ファイルリンクの構造刷新**: 📎 マーカーは markdown 上だけに存在し（subpage の `[[]]` と同格）、表示アイコンは CSS 装飾に。アイコンとテキストの間にカーソルが入らず、全選択 cut でアイコンごと消えます
- **D&D 後の元リンク残存**: リンクをツリーや別エディタへ D&D した後、移動元 md からリンクが消えないことがある問題を根治（host がファイル実体を直接更新 — 移動元 md が開かれていなくても消えます）

### 新機能

- **リンクの clipboard 一体化**: リンクテキスト全選択（ダブルクリック / shift+矢印 / 行選択）の cmd+C/X で `[📎 name](files/...)` / `[[title]](page.md)` / `[text](doc.md)` がマーカー + パス込みで clipboard に載り、cmd+V でリンクとして復元。段落・リスト・テーブルなど場所を問いません。部分選択は従来どおりテキストコピー
- **md 内のリンク D&D 移動**: 📎/subpage リンクのアイコンを掴んで同じ md 内の別の場所（段落⇄リストなど）へドロップすると移動。移動で空になった行は自動掃除
