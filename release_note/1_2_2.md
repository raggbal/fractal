# Release 1.2.2

## ハイライト

- **添付ファイルの中身検索**: PDF / Word (.docx) / Excel (.xlsx) / PowerPoint (.pptx) の中身が Notes の検索ボックスと fractal-search CLI（Claude 用 AI skill）でヒットするようになりました。tree のファイル項目・outliner node の 📎 添付・md 本文の 📎 添付、すべてが対象です（Windows / macOS 両対応）
- **どこにあるかが分かる**: ヒットに位置が付きます — PDF は `p.5`、PowerPoint は `slide 3`、Excel は `売上集計!B12`（シート名+セル）
- **どこから参照されているかが分かる**: ヒットしたファイルを参照している outliner node / md へのリンクが表示され、クリックでジャンプできます（検索表示の後に非同期で解決 — 検索は遅くなりません）

## 詳細な変更内容

### 新機能

- 検索結果に第 4 セクション「Files」を新設（7 言語対応）。ヒットのクリックで OS 既定アプリが開く
- 抽出はファイル単位でキャッシュ（mtime ベース）— 2 回目以降の検索は高速。キャッシュは note フォルダ外（S3 sync / Clean Unused Files の対象外）に置かれ、添付削除と同時に消去
- 検索クエリの NFKC 正規化（添付検索）: 全角括弧・全角英数のクエリでもヒット
- fractal-search CLI: `--scope file`（デフォルト scope にも含む）、位置付き出力、npm install 不要の配布を維持

### 実装メモ

- OOXML 抽出は外部依存ゼロの自作（ZIP/XML パーサ + zip bomb ガード）。extension と CLI はミラー実装で、一致テストが同期を担保
- PDF は pdfjs-dist@4.10.38（exact pin・fake worker で単一バンドル・遅延ロード）。Electron アプリでは PDF のみ自動スキップ（OOXML は動作）
- 検索できなかったファイルは理由付きで記録（暗号化/サイズ超過/PDF 利用不可など — silent に消えない）

### 対象外（既知の制限）

- 旧 Office 形式（.doc / .xls / .ppt）
- スキャン PDF（OCR なし）・パスワード保護文書
- ToUnicode 非埋込の古い日本語 PDF（skip として記録・将来 cmaps 同梱で対応可能な設計）
- Word 文書のページ番号表示（フォーマット上ページ情報が存在しないため）
