# Release 1.3.17

## ハイライト

- **linked folder で同名があっても、ドラッグ移動はダイアログなしで連番になる** — `a.md` → `a-1.md`、`assets` → `assets-1`。コピー & ペーストと同じ規則にそろった
- **`Cmd+C` → そのまま `Cmd+V` で、その場に複製できる** — ファイル・md・フォルダとも、元と同じフォルダに `-1` 付きで複製される
- **md をコピー・移動しても、中身の無い `images/` `files/` フォルダが作られなくなった**

## 詳細な変更内容

### 変更

**同名衝突は常に連番（1.3.16 の 3 択を廃止）**

- 1.3.16 で入れた「中止 / 上書き / 別名」の確認ダイアログは、実際にはフォルダを含むドラッグでしか出ず、コピー & ペーストは最初から連番だった。操作によって挙動が違って不自然なので、ダイアログをやめて**すべて連番**にそろえた
- 1 ファイルだけをドラッグしたときの「同じ名前が既にあります」エラーも無くなり、連番で移動する
- 連番で名前が変わっても通知は出ない（コピー & ペーストと同じ）
- 既存のファイル・フォルダが上書きされることは無い
- **フォルダ名のドットは拡張子として扱わない**: `assets.bak` → `assets.bak-1`（ドラッグ・貼り付け・Duplicate のすべてで同じ。以前は貼り付けと Duplicate で `assets-1.bak` になっていた）
- 変わらないもの: New Folder / Rename で同名を打ったときの拒否、自分自身や子孫フォルダへの移動の拒否、linked folder の外（note ツリー・md・outliner）との間の同名処理

### 修正

**`Cmd+C` → `Cmd+V` のその場複製**

- 項目を選んで `Cmd+C` し、**選択を変えずに** `Cmd+V` すると、同じフォルダに連番で複製される（ファイル・md・フォルダ・複数選択とも）
- 以前は、ファイルでは何も起きず、フォルダは自分自身の中へ貼ろうとして失敗していた
- `Cmd+C` のあと**別のフォルダを選んで** `Cmd+V` した場合は、従来どおりそのフォルダの中に複製される

**linked folder が操作を受け付けなくなる問題**

- 同じフォルダへのドラッグ（何も起きない操作）、自分の中へのドラッグ（エラー）、件数確認でのキャンセルなどのあと、その linked folder がドラッグも貼り付けも受け付けなくなることがあった。どの結末でも、次の操作がすぐ効くようになった

**空の `images/` `files/` フォルダが作られる問題**

- md をコピー・移動すると、画像や添付が 1 つも無いのに、移動先・複製先に空の `images/` `files/` ができていた
  - サブページへのリンクを持つ md（サブページもいっしょに複製される）
  - 画像・添付へのリンクはあるが、実体のファイルが無い md
- `images/` `files/` は、**実体をコピーするときだけ**作るようになった。outliner の page・ノード画像・ノード添付を貼り付け・書き出しする経路も同様
- 既に作られてしまった空フォルダは自動では消えないので、不要なら手で削除してください

**1.3.16 のリリースノートの訂正**

- 1.3.16 では「移動・コピーで同名があると 3 択が出る」と書いたが、実際にはコピーは常に連番で、3 択が出たのは一部のドラッグだけだった。この 3 択は今回の版で廃止した
